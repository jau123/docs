Use MeiGen in ChatGPT or [connect your MCP client](/en/mcp/remote). For an existing local npm integration or your own image API key, see [local setup](/en/mcp/setup).

## ChatGPT

1. Open [MeiGen in the official ChatGPT store](https://chatgpt.com/plugins/plugin_asdk_app_6ab66d24f56481919361b6c33f7c1928) and select **Install**.
2. Sign in to your MeiGen account and complete the connection. No API key or Node.js is needed.
3. Select or mention **MeiGen** in a conversation, then ask it to find inspiration or create an image or video.

Search the gallery with `search_gallery`. Search uses the account’s search allowance. Image and video generation use purchased credits. Check the available models and prices with `list_models` before generating.

For available tools and permissions, see [the tool reference](/en/mcp/remote#tools). For a cutout, poster or other image workflow, get the required materials and price with `list_skills`. See [Skills inputs](/en/api-reference/skills/overview), [video drafts](/en/mcp/drafts) and [recovering a request](/en/mcp/composable-workflows).
