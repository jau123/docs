**MeiGen** helps you discover inspiration and create images and videos with the latest AI models in the AI tools you use. Install the ChatGPT plugin, connect through remote MCP, or use the open-source local server.

## ChatGPT

1. Open [MeiGen in the official ChatGPT store](https://chatgpt.com/plugins/plugin_asdk_app_6ab66d24f56481919361b6c33f7c1928) and select **Install**.
2. Sign in to your MeiGen account and complete the connection. No API key or Node.js is needed.
3. Select or mention **MeiGen** in a conversation, then ask it to find inspiration or create an image or video.

Try: *“Use MeiGen to find minimalist product photography inspiration. Show me reference images and their prompts.”*

Search does not spend generation credits. Generation uses your purchased MeiGen credits; daily free credits do not apply. Review the model, image count and total price before generating.

The ChatGPT plugin and remote OAuth connection use MeiGen Cloud. Local npm remains available for existing MeiGen API-key integrations and explicitly selected external-provider BYOK. Version 3.0.0 removes ComfyUI and the bundled offline prompt library; see the [migration notes](/en/mcp/comfyui).

## Compose inside another workflow

Keep the upstream script, prompt, model/provider, count and approved budget. Creative helpers are optional. Use persistent UUID `requestId`, `wait: false`, structured results and `check_generation` to submit frames/videos and resume them without re-approving every step. The caller owns bounded scheduling, previews and downloads. See [the complete workflow contract and examples](/en/mcp/composable-workflows).

## What is MCP?

Model Context Protocol (MCP) is an open standard that allows AI assistants to use external tools. When you install MeiGen as an MCP server, your AI assistant gains the ability to generate images and videos, run semantic search across the MeiGen community prompt gallery, and enhance prompts — all through natural language. Standard remote MCP and local npm support anonymous public search; the official ChatGPT plugin requires account authorization for search. Prompt enhancement is local. In 3.0.0, inspiration search uses the online gallery only, without an offline fallback; unavailable services return an error.

## Five dedicated image workflows

Ask for a cutout, product detail images, a marketing poster, a new background or image enhancement. The agent should inspect `list_skills`, prepare the actual materials, submit the matching tool and use `check_skill` for results. It generates request UUIDs itself. A specified count/quality is already your instruction; only unresolved scope or an Upscale warning needs a decision.

| Workflow | Required material | Optional material | Output |
| --- | --- | --- | --- |
| Remove Background | One source image | None | One transparent PNG |
| Product Detail Images | One product photo and selected modules/count | Product name, verified selling points, logo, model image, two extra angles | 1–6 paid images |
| Marketing Poster | Brand, event or topic | Copy, logo, three product images, style reference | One paid poster |
| AI Backgrounds | One product photo | Mode; custom mode requires a background description | One paid image |
| Upscale | One original still JPEG/PNG/WebP | Crisp/creative mode | One paid enhanced image |

Skills use purchased credits only, with no free attempts or daily credits. BYOK do not supply these workflows. See the [complete Skills API and material guide](/en/api-reference/skills/overview).

For posters, put visible copy in `content`; use `extraNotes` or `customStyle` for design directions. `autoCopy: false` preserves supplied wording, with selected-language translation still possible. See [poster field roles and a complete MCP call](/en/api-reference/skills/marketing-poster#mcp-call-example).

## Choose a connection

ChatGPT users should install the [official plugin](#chatgpt). Other new users should [connect with remote OAuth](/en/mcp/remote) at `https://www.meigen.ai/api/mcp`, then sign in to MeiGen and approve access in the host. No API key or Node.js is needed. Use a compatible host if OAuth is unavailable.

[Local npm](/en/mcp/setup) retains existing API-key compatibility for generation, public search and Skills, BYOK, local file preparation, prompt enhancement and local preferences. It has no OAuth login or private-library tools. API keys are not offered as another new-user authentication method. Existing Claude/OpenClaw plugin stdio connections and creative instructions update separately; avoid duplicate tools when switching connections.

The 3.0.0 local image providers are MeiGen (existing legacy key) and OpenAI-compatible APIs, in that priority order. ComfyUI is removed. Skills and video remain MeiGen Cloud features; use `list_models` and `list_skills` for current models and prices.

## Tools

These **14 shared tools** form the common set. Local npm 3.0.0 has 16 tools, including two local helpers. Standard remote MCP has 19, including the five private-library tools below. The currently published official ChatGPT plugin has 14 tools; its update to 19 tools and six search results per batch still requires store approval. A backend or npm release does not make those new ChatGPT features available.

| Tool | Purpose | MeiGen account authorization |
| --- | --- | --- |
| `generate_image` | General image generation; local can use configured backends | For MeiGen Cloud |
| `generate_video` | MeiGen Cloud video generation | Yes |
| `check_generation` | Status/recovery by generationId or requestId | Request-ID lookup requires the owning account |
| `list_models` | Available models and capabilities | No |
| `search_gallery` | Search public prompts and image previews; batch limits vary below | Standard MCP/local: optional; official ChatGPT plugin: required |
| `get_inspiration` | Read a public gallery entry | No |
| `list_skills` | Five workflows, materials, live prices and input schemas | No |
| `upload_skill_image` | Prepare real image URLs or attachment bytes | Yes |
| `remove_background` | One transparent cutout | Yes |
| `generate_product_detail_images` | 1–6 paid product modules | Yes |
| `generate_marketing_poster` | One promotional poster | Yes |
| `generate_ai_background` | One white, smart or custom background | Yes |
| `upscale_image` | Enhance one original still image | Yes |
| `check_skill` | Private Skill receipt, module status and recovery | Yes, owning account; legacy local calls require the original key |

Local additionally provides `enhance_prompt` and `manage_preferences` without a MeiGen account. Version 3.0.0 removes `comfyui_workflow` and offline prompt fallback.

| Public gallery search | Default / maximum results per batch | Account access |
| --- | --- | --- |
| Standard remote MCP | 3 / 3 | Optional OAuth; anonymous searches are IP-limited |
| Local npm 3.0.0 | 3 / 3 | Anonymous, or an existing legacy key |
| Official ChatGPT plugin | Published version: 3 / 3; update awaiting store approval: 6 / 6 | OAuth with search permission (`meigen:search`) |

Authorized searches use the account's [daily search allowance](/en/features/gallery#search), not generation credits. Starting a search uses that allowance; continuation pages do not count again. Standard remote MCP and local 3.0.0 support pagination; the official ChatGPT plugin's next-batch cards are part of its update awaiting store approval. To see another batch, preserve the returned query and snapshot ID and pass `nextOffset` as `offset`; stop when `hasMore` is false. A different direction starts a new query. Keep original generation request IDs during recovery; a timeout is not permission for a new paid task.

## Private library through remote OAuth

Standard remote MCP provides `search_favorites`, `list_boards`, `search_history`, `get_library_item` and `save_favorite`. Connect with OAuth and approve the separate library read/write permissions when requested; existing connections do not gain them automatically. Local npm and API keys cannot access these tools. Their addition to the official ChatGPT plugin is still awaiting store approval.

Lists contain prompt excerpts of at most 500 Unicode code points. Use `get_library_item` for a selected user prompt in pages of 8000 code points by default, up to 16000; internal Skill prompts are never returned. Saving requires an explicit request or prior opt-in, preserves existing notes on repeat calls and only supports owned private board destinations. Favorites are context for preferences, not a replacement for current instructions.


<Note>
  Video capabilities differ by model — quality tiers, available durations and resolutions, audio, reference-video continuation, and whether a first frame is required. Some models are image-to-video only. Call `list_models` for the current lineup, or see the [model comparison](/en/features/models).

  Seedance 2.5 uses model ID `seedance-2-5`, supports 4–30 second 480p/720p/1080p output and reference-video continuation, and has no `tier` option.

  `generate_video` requires an explicit `model` — there's no platform default. Reference media are arrays: `referenceVideos` (mp4 / mov) and `referenceAudios` (wav / mp3, ≤15MB per clip). The **local npm server accepts local file paths** here and uploads them for you; the remote server needs URLs that already point at `images.meigen.ai` — a previous generation's `videoUrl`, or a file from [`POST /api/upload/reference-video`](/en/api-reference/endpoint/generate#upload-reference-videos-and-audio). An arbitrary public URL is rejected before charging. The singular `referenceVideo` is still accepted as a one-element alias, and `referenceVideoDuration` is a deprecated, validated compatibility hint that never sets the billed duration — omit it, the server probes every clip itself.

  Per-model caps come from `list_models` (`capabilities.video.referenceVideo` and `capabilities.video.referenceAudio`): Seedance 2.5 takes up to 10 videos and 10 audio clips, 2–30s each and 30s in total per kind; Seedance 2.0 takes up to 3 and 3, 2–15s each and 15s in total. **Seedance 2.0 cannot run on audio alone** — its reference audio needs at least one reference image or reference video alongside it, while Seedance 2.5 accepts audio-only requests.

  Billing uses the **sum** of the reference video durations plus your output duration, never below the minimum-billable floor. Reference audio is free: it never enters that sum, and a request carrying audio but no reference video is priced at the model's direct rate.
</Note>

### GPT Image 2.5

Call `list_models` first to check availability. **Local npm 3.0.0 supports** `model: "gpt-image-2.5"` or its `modelId` alias, `quality` (`low`, `medium`, `high`, `xhigh`, `max`) and `modelVariant: "sunburst"` (default) or `"flare"`. If both `model` and `modelId` are supplied, they must match. The [remote MCP server](/en/mcp/remote) and [REST API](/en/api-reference/endpoint/generate) use `modelId` with `modelVariant`. GPT Image 2 remains a separate model with its original pricing.
