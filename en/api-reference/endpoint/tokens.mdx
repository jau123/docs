---
title: "API Tokens"
description: "Create and manage API tokens in your MeiGen account"
---

Create and revoke tokens at [API Keys](https://www.meigen.ai/profile/api-keys) using a desktop browser. Each account supports up to 5 active tokens.

Copy your token when you create it. Its full value is shown only once.

Pass the token as a Bearer credential on any authenticated endpoint:

```bash
curl -X POST https://www.meigen.ai/api/generate/v2 \
  -H "Authorization: Bearer meigen_sk_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a minimalist logo"}'
```

<Warning>
  **API tokens can only spend purchased credits.** Daily free credits are not available via the API.
</Warning>

To add credits to the account that owns your key, choose **Top Up** on your [profile](https://www.meigen.ai/profile).
