**Skills** is a set of guided, e-commerce-focused workflows — a separate entry point from general [image and video generation](/en/features/generate). Instead of writing a prompt from scratch, you fill in a short form for your use case and MeiGen produces the finished asset.

Open **Skills** from the sidebar on web, or from the Create tab in the iOS/Android app, to see the available workflows. Each one has an example project you can preview before running it yourself.

## Product Detail Images

Turn one product photo into a full set of detail-page images — the kind used on marketplace listings.

**You provide:**

| Field | Notes |
| --- | --- |
| Product photo | Required |
| Product name | Required |
| Selling points | Optional — leave blank and the AI extracts them from the photo |
| Target platform | Adjusts layout and style conventions |
| Aspect ratio | For the output images |

**Optional content modules** — pick which sections to include in the set:

Hero Banner · Specs & Parameters · Detail Close-up · Lifestyle Scene · Model Shot · Size Chart · Material · Usage Instructions · Brand Closing

## White Background

Turn a casual product photo into a clean, white-background product image.

**You provide:**

- Product photo (required)

## Marketing Poster

Turn a one-line idea into a promotional, event, or recruitment poster.

**You provide:**

| Field | Notes |
| --- | --- |
| Theme | One sentence describing the poster |
| Copy | The text to appear on the poster |
| Extra requirements | Free-text, optional |
| Reference image | Optional — use your own brand assets |
| Poster text language | Chinese, English, Korean, Japanese, Russian, French, or Spanish |

## Where Results Go

Skills output lands in your regular [generation history](/en/features/generate#generation-history) alongside everything else you create — you can save it to favorites or [publish it to the gallery](/en/features/gallery#publishing-your-work-to-the-gallery) the same way.

## Credits

These workflows have **their own Skill prices**, separate from the general image generator. Their GPT Image 2.5 configuration uses **Sunburst at 2K**; the workflow selects the model for you.

| Workflow | Option | Credits per generated image |
| --- | --- | --- |
| Product Detail Images | Fast / Pro | 5 / 18 |
| Marketing Poster | Fast / Pro | 5 / 18 |
| White Background (White mode only) | Fixed quality | 5 |

Fast uses Standard quality; Pro uses High quality. A multi-image set costs the per-image price multiplied by the number of images. Check the workflow's displayed total and availability before submitting; these prices do not apply to a general `gpt-image-2.5` API request. AI Backgrounds in Smart or Custom mode uses another model and the price shown in its interface. Other Skills may also use different models and prices.

For general generation, see the [model comparison page](https://www.meigen.ai/model-comparison).
