## Video Models

### HeyGen Video 1

Affordable video, optimized from MiniMax H3, with native audio.

<Note>
  Available on Web, API and MCP. Compatible App versions receive HeyGen through capability negotiation; older versions keep their existing model list. Reference-video availability follows the live model catalog and is available to existing HeyGen-compatible App versions.
</Note>

| Setting | MeiGen configuration |
| --- | --- |
| Model ID | `heygen-video-1` |
| Duration | 5–15 seconds, integer steps; default 5 |
| Resolutions | 480p, 768p (default), 1080p, 2K |
| First frame | One image, no last frame; output follows the image ratio |
| Content references | Up to 9 images; separate from first-frame mode |
| Reference audio | Up to 3 WAV/MP3 clips, 1–15 seconds each, 45 seconds total, 16MB each; requires a content-reference image |
| Combined reference limit | 12 items |
| Reference video | When enabled in the live catalog: up to 3 MP4 clips, 1–5s each, 15s total, 16MB each; aspect ratio 1:4–4:1 |
| Ratios | Auto (default) uses the prompt and reference image. Six ratios at 480p/768p; 16:9 or 9:16 at 1080p/2K. First-frame mode follows the image at every resolution |

First-frame and content-reference inputs use separate panels. Only the selected panel is submitted; switching panels preserves the other panel's materials. Video or audio is submitted with content references. Video-only and image + video requests are supported. **Reference video cannot currently be combined with separate reference audio**; embedded video audio is allowed. This is a temporary MeiGen/Gateway compatibility restriction based on testing, not a published HeyGen model limit. Conflicting requests are rejected before charging; images + audio remain supported.

HeyGen's `@character` mentions are a MeiGen convenience: saved character images are submitted as ordinary content references, without Seedance assets. Reference up to 3 characters; one character uses up to 2 images, while multiple characters use 1 image each. Character images and uploads share the 9-image and 12-item limits after deduplication and use content-reference pricing. Character mentions select the content panel; the first-frame draft is preserved but not submitted.

#### Pricing

| Resolution | Text / first frame | Content references |
| --- | --- | --- |
| 480p | 2 credits/sec | 4 credits/sec |
| 768p | 3 credits/sec | 6 credits/sec |
| 1080p | 9 credits/sec | 18 credits/sec |
| 2K | 9 credits/sec | 18 credits/sec |

Credits = (output seconds + the sum of each reference video’s duration rounded up to whole seconds) × the rate for the submitted input mode. With no reference video, only output seconds count. The interface selects the rate automatically. Audio does not add billable seconds, but requests with content images, videos or audio use the higher content-reference rate. There is no minimum-seconds multiplier. For example, 5 seconds at 768p costs 15 credits with text or a first frame, and 30 credits with content references. A 4.1s reference video + 5s output at 768p costs (5 + 5) × 6 = 60 credits. This is a premium model and uses purchased credits only.

#### Image and prompt handling

Images reuse MeiGen's shared upload component: JPEG/PNG/WebP/GIF, an 8000px-per-side upload guard, compression targeting 2MB and 2048px when needed, and a 10MB upload-gateway cap. AVIF is converted before upload. These are MeiGen upload settings, not published HeyGen pixel limits. Library/gallery images are also checked before charging: readable image data, a verifiable size no larger than 16MB, and a direct HTTPS URL without redirects.

HeyGen accepts up to 32,000 prompt characters. MeiGen reserves space for protected reference instructions and native reference labels before applying the shared long-prompt compression. Within the remaining budget no compression is needed; beyond it the compressor targets 50 characters below that budget. On compression failure the body is shortened to fit, while reference instructions are protected and checked. The model receives labels such as `<Picture 1>` and `<Audio 1>`; use the editor's `@` mentions to insert them.

Sources: [HeyGen model guide](https://developers.heygen.com/docs/models/heygen-video) and [AI Gateway model](https://vercel.com/ai-gateway/models/heygen-video-1). MeiGen's current UI limits and submit-time credit quote are authoritative.

Seedance 2.5 is the long-duration Seedance model on MeiGen. It supports text-to-video, first/last-frame image-to-video, up to 30 content-reference images, and reference-video continuation. Content images, reference videos and reference audio can all be used in the same request and are three independent budgets. Frame references and reference-video continuation use `adaptive` ratio so the output follows the input media; text-to-video and content-reference requests can use an explicit supported ratio.

#### Pricing

| Resolution | Direct | With reference video |
| --- | --- | --- |
| 480p | 18 credits/sec | 11 credits/sec |
| 720p | 39 credits/sec | 24 credits/sec |
| 1080p | 90 credits/sec | 54 credits/sec |

Direct generation bills only the selected output duration. With one or more reference videos, billing uses the **sum** of their durations:

`billable seconds = max(sum of reference video durations + selected output duration, ceil(selected output duration × 5 / 3))`

The minimum-billable floor is 7 seconds for a 4-second output, 9 for 5 seconds, and 50 for 30 seconds. Output length is always the selected 4–30 seconds; the billing floor does not lengthen the generated clip. **Reference audio is free** — its duration never enters the sum, and a request with audio but no reference video is billed at the direct rate.

| Scenario | Calculation | Total |
| --- | --- | --- |
| 480p × 5s direct | 18 × 5 | **90** |
| 720p × 5s direct | 39 × 5 | **195** |
| 480p, one 2s reference video + 5s output | 11 × max(2+5, 9) | **99** |
| 720p, one 2s reference video + 5s output | 24 × max(2+5, 9) | **216** |
| 480p, 2s + 3s reference videos + 5s output | 11 × max(2+3+5, 9) = 11 × 10 | **110** |
| 480p, one 2s reference video + 1 reference audio clip + 5s output | 11 × max(2+5, 9); audio adds 0 | **99** |
| 480p × 5s direct + 1 reference audio clip | 18 × 5; no reference video, so the direct rate applies | **90** |
| 480p × 30s direct | 18 × 30 | **540** |

Seedance 2.0 is the three-tier Seedance option. It supports text-to-video, image-to-video (first/last frame or content reference), and video continuation. All outputs include AI-generated audio. The `adaptive` aspect ratio automatically matches the reference image/video dimensions. Both Seedance 2.0 and 2.5 support **character assets**: save a character once, then reference it with `@` in your prompt to keep the same subject across shots.

Two reference-image modes: **first/last frame** (default, up to 2 images) sets the opening and/or closing frame; **content reference** guides style or subject instead of fixing a frame position and accepts up to 9 images. Content images, reference videos and reference audio can all be used in the same request and are three independent budgets.

**Three tiers**, picked from the tier switch (Mini / Fast / Pro) in the video sidebar. Same Seedance 2.0 model, same params, just different rendering quality and price:
- **Mini** (default): cheapest and most lightweight; 480p / 720p
- **Fast**: quick turnaround at 480p / 720p
- **Pro**: higher fidelity, with **native 1080p and 4K** rendering (4K is direct-generation only)

All three tiers support multi-clip reference-video continuation and reference audio — continuation output tops out at 1080p even on Pro.

#### Pricing

Per-second. Rate depends on **tier** (Mini / Fast / Pro) × **whether a reference video is uploaded**:

| Resolution | Mini Direct | Mini With reference video | Fast Direct | Fast With reference video | Pro Direct | Pro With reference video |
| --- | --- | --- | --- | --- | --- | --- |
| 480p | 9/sec | 7/sec | 13/sec | 8/sec | 14/sec | — |
| 720p | 16/sec | 13/sec | 20/sec | 14/sec | 22/sec | 16/sec |
| 1080p | — | — | — | — | 42/sec | 28/sec |
| 4K | — | — | — | — | 100/sec | — |

Mini and Fast only support 480p / 720p. Pro adds native 1080p and 4K for direct generation; with a reference video, Pro is limited to 720p / 1080p (no 480p rate).

**With-reference-video billing rule (all tiers):**

`billable seconds = max(sum of reference video durations + your selected duration, min billable)`

Output length is always your selected duration (4–15), independent of the reference videos' lengths. **Reference audio is free** and never enters the sum; attaching audio without any reference video keeps the direct rate.

Total credits = the selected tier's rate at the selected resolution × output seconds. Default settings are **Lite, 480p, 4 seconds — 16 credits**. Lite remains a premium model; daily free credits do not apply.

**Examples:**

| Scenario | Calculation | Total |
| --- | --- | --- |
| Lite 480p × 4s (default) | 4 × 4 | **16** |
| Lite 720p × 10s | 6 × 10 | **60** |
| Lite 1080p × 4s | 28 × 4 | **112** |
| Standard 480p × 4s | 16 × 4 | **64** |
| Standard 1080p × 4s | 50 × 4 | **200** |

API and MCP keep the model ID `grok-video`. Set `tier` to `lite` or `standard`; omitting it uses Lite. Set `resolution` to `480p`, `720p`, or `1080p`. Read current defaults and pricing from [List Models](/en/api-reference/endpoint/models); do not send the upstream provider's model ID as `modelId`.

## Known Limitations

<AccordionGroup>
  <Accordion title="Nanobanana 2 — Stricter content filtering" icon="triangle-exclamation">
    This model is more sensitive to content involving real people, celebrities, brand logos, and face-swap requests. Prompts that work on other models may be rejected here. If you get a content violation error, rephrase your prompt to remove specific names or try a different model.
  </Accordion>

  <Accordion title="Flux 3 Image Klein — No reference images" icon="triangle-exclamation">
    This base model generates images from text only. The reference image upload section is hidden while it is selected. If you need reference images, switch to another model.
  </Accordion>

  <Accordion title="Midjourney V8.2 — Single reference image only" icon="triangle-exclamation">
    Midjourney V8.2 accepts only 1 reference image, while other image models accept between 3 and 16. In exchange it offers more control over how the reference is used (content vs. style reference).
  </Accordion>

  <Accordion title="Midjourney V8.2 — Returns 4 candidate images" icon="info-circle">
    Unlike other models that return a single image, Midjourney V8.2 returns 4 candidate images per generation. All candidates are saved and can be browsed in the image detail dialog. You are only charged once (12 credits at 1K / 18 credits at 2K) for all 4 images.
  </Accordion>

  <Accordion title="GPT Image 2.0 — Stricter moderation" icon="triangle-exclamation">
    GPT Image 2.0 applies stricter moderation than other models to real people, celebrities, brand logos, and adult/violent content. Rephrase your prompt to drop specific names, or try a different model.
  </Accordion>

  <Accordion title="Seedance 2.0 — Per-second pricing + With-reference-video minimum" icon="circle-info">
    Seedance bills **per second**, not per image — and uploading a reference video switches to a separate rate table with a minimum-billable floor. With several reference videos, the billed seconds use the **sum** of their durations plus your selected output duration, so each extra clip raises the total. Reference audio is free and never enters that sum, and a request with audio but no reference video stays on the direct rate. See the **Seedance 2.0** section above for the full rates and formula.
  </Accordion>

  <Accordion title="Seedance 2.0 — Reference audio needs an image or video" icon="triangle-exclamation">
    On Seedance 2.0, reference audio only works alongside at least one reference image (a saved character counts) or one reference video — audio on its own is rejected before any credits are deducted. Seedance 2.5 has no such requirement and accepts audio-only requests.
  </Accordion>

  <Accordion title="Seedance 2.5 — No Mini / Fast / Pro tier" icon="circle-info">
    Seedance 2.5 has one quality level and supports 480p / 720p / 1080p. Do not send `tier`; use Seedance 2.0 Pro when you specifically need 4K.
  </Accordion>

  <Accordion title="Seedance 2.0 Mini — 480p / 720p only" icon="triangle-exclamation">
    The Mini tier (the default) is the lightweight option, capped at 720p. For 1080p or 4K output, switch to **Pro** — note that reference-video continuation on Pro tops out at 1080p (4K needs direct generation with no reference video).
  </Accordion>

  <Accordion title="Grok Video 1.5 — First frame required" icon="triangle-exclamation">
    Grok Video 1.5 is image-to-video only — you **must** upload a starting (first-frame) image. Pure text-to-video is not supported. The output aspect ratio follows your input image. If you want text-to-video, use Seedance 2.5, Seedance 2.0, or Veo 3.1.
  </Accordion>

  <Accordion title="Grok Video 1.5 — Lite / Standard and 1080p" icon="triangle-exclamation">
    Both tiers support 480p, 720p and 1080p. Lite is the default; price depends on both tier and resolution. For 4K, use Seedance 2.0 Pro or Veo 3.1.
  </Accordion>

  <Accordion title="Veo 3.1 — Limited aspect ratios" icon="triangle-exclamation">
    Veo 3.1 only supports 16:9 / 9:16 (plus Auto). Square (1:1), 4:3 / 3:4 portrait, and other ratios are not available. For wider ratio support, use Seedance 2.5 or Seedance 2.0.
  </Accordion>

  <Accordion title="Veo 3.1 — 4k costs no extra credits, but needs a paid account" icon="circle-info">
    720p / 1080p / 4k all cost the same on Veo 3.1, so 4k costs no extra credits. Two things to know: 4k is **locked for free accounts** (selecting it opens the upgrade dialog), and rendering takes longer — 4k typically takes 6–8 minutes versus 1–4 minutes for 720p / 1080p. The same 4k lock applies to Seedance 2.0 Pro.
  </Accordion>
</AccordionGroup>
