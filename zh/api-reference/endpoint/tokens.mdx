---
title: "API Token"
description: "在 MeiGen 账户后台创建和管理 API Token"
---

前往 [API Keys](https://www.meigen.ai/profile/api-keys)（桌面浏览器） 创建和撤销 Token。每个账号最多同时拥有 5 个活跃 Token。

创建后请立即复制并妥善保存 Token；完整值仅显示一次。

在任何需要认证的端点将 Token 作为 Bearer 凭证传入：

```bash
curl -X POST https://www.meigen.ai/api/generate/v2 \
  -H "Authorization: Bearer meigen_sk_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a minimalist logo"}'
```

<Warning>
  **API Token 只能消耗购买积分。** 每日免费积分不可用于 API 调用。
</Warning>

需要充值时，请登录创建该密钥的账号，在[个人资料](https://www.meigen.ai/profile)中选择**充值**。
