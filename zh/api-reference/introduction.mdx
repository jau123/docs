MeiGen API 支持以编程方式生成图片、视频，以及[五项专用图片 Skills](/zh/api-reference/skills/overview)。Skills 的上传、批次和 requestId 恢复契约独立，请查对应指南。

<Tip>
  **偏好自然语言？** 如果你使用 Claude Code、Cursor 或 OpenClaw，可以试试 [MCP 服务器](/zh/mcp/overview)，无需写 HTTP 代码即可生成图片。
</Tip>

## 认证

API 请求需要 Bearer token。有两种认证方式：

### API Token（推荐）

使用以 `meigen_sk_` 开头的 API Key。用桌面浏览器在 [API Keys](https://www.meigen.ai/profile/api-keys) 创建。

```bash
Authorization: Bearer meigen_sk_YOUR_API_KEY
```

<Warning>
  API Token 只能使用**购买积分**。每日免费积分不可用于 API 调用。在发起 API 请求前，请确保你的账户有购买积分。
</Warning>

### Session Token

面向 meigen.ai 内部的浏览器集成，使用登录后的 session access token。每日免费积分**仅可用于基础模型**（当前为 Flux 2 Klein、Agnes Image 2.5 Flash 和 Agnes Video 2.5 Flash）；其余模型始终需要消耗注册赠送或购买积分。第三方集成请统一使用上面的 API Token。

## 基础 URL

```
https://www.meigen.ai/api
```

选模型前先调用[模型列表](/zh/api-reference/endpoint/models)。以下示例要求 `gpt-image-2.5` 已启用。该端点仍返回 GPT Image 2 时，可继续使用旧模型 ID 与原有价格。

## 请求格式

所有请求体必须以 JSON 格式发送，并设置 `Content-Type: application/json` 请求头。

```bash
curl -X POST https://www.meigen.ai/api/generate/v2 \
  -H "Authorization: Bearer meigen_sk_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a minimalist logo", "modelId": "gpt-image-2.5", "resolution": "2K", "quality": "low", "modelVariant": "sunburst"}'
```

## 响应格式

所有响应返回 JSON。成功响应包含 `success: true` 字段：

```json
{
  "success": true,
  "generationId": "abc-123",
  "status": "processing"
}
```

错误响应包含 `error` 字段：

```json
{
  "error": "Error description"
}
```

## 异步生成

图片生成是**异步**的。流程如下：

1. **提交**生成请求 → `POST /api/generate/v2`
2. **轮询**状态端点 → `GET /api/generate/v2/status/:id`
3. 当 `status === "completed"` 时，直接从状态响应读取 `imageUrl` / `imageUrls` / `videoUrl`。

### 轮询最佳实践

- **推荐间隔**：每 3 秒检查一次状态
- **停止条件**：当 `status` 为 `completed` 或 `failed` 时
- 当 `status` 为 `processing` 时，响应会带上 `expectedWaitSeconds`（该模型 + 分辨率的预估剩余等待秒数）与 `pollHintSeconds`（建议继续轮询的剩余秒数，归零表示可以停止）。用这两个字段替代写死的超时时间——实际耗时会随模型、分辨率、时长变化。各模型典型耗时见[模型](/zh/features/models)页面。
- 客户端过早停止轮询不影响结果：任务仍会跑完并照常计费，请务必轮询到 `status` 进入终态。

## 缓存

部分 GET 端点返回缓存响应：

| 端点 | 缓存时长 |
| --- | --- |
| `GET /api/models` | 1 小时（另有 stale-while-revalidate）|
| `GET /api/images/:id` | 1 小时 |
| `GET /api/skills` | 最多 5 分钟；错误不缓存 |
| `POST` 端点 | 无缓存 |

因此模型清单的变更——上新、下线、切换默认模型——最长可能 1 小时后才可见，请据此设计自己的刷新节奏。

## 积分

每次生成会从账户扣除积分。图片模型按张计费（单价可能随分辨率与画质变化）；视频模型按秒或按次计费，取决于具体模型。各模型完整定价表见[模型](/zh/features/models)页面。

## 错误响应

以下表格面向通用生成。Skills 请遵守[按 code 区分的恢复规则](/zh/api-reference/skills/overview#计费与错误处理)，409 或 5xx 不代表应自动新建付费请求。

| 状态码 | 含义 |
| --- | --- |
| 400 | 请求无效 — 参数错误 |
| 401 | 未授权 — token 无效或缺失 |
| 402 | 需要付费 — 积分不足 |
| 403 | 禁止访问 — 该模型在当前平台不可用 |
| 404 | 未找到 |
| 409 | 冲突 — 幂等键已被占用，换一个重试 |
| 5xx | 服务器错误 — 稍后重试；生成失败的积分会自动退还 |

`POST /api/generate/v2` 的错误响应会附带便于排查的额外字段，且大多在人类可读的 `error` 之外还带一个可供程序判断的 `code`：

| `code` | 状态码 | 含义 |
| --- | --- | --- |
| `insufficient_credits` | 402 | 本次请求的可用积分不足 |
| `premium_model_paywall` | 402 | 所选模型需要购买积分（每日免费积分不适用） |
| `unsupported_quality` | 400 | 所选 GPT Image 模型不支持此质量档位 |
| `unsupported_model_variant` | 400 | 型号选项不合法，或为 GPT Image 2.5 以外的模型传了 `modelVariant` |
| `invalid_model` | 400 | 模型不存在、未启用，或仅供技能工作流使用 |
| `unsupported_duration` | 400 | 该模型不支持这个时长 |
| `unsupported_tier` | 400 | 该模型不支持这个档位 |
| `unsupported_resolution` | 400 | 该模型/档位不支持这个分辨率 |
| `first_frame_required` | 400 | 该模型必须提供首帧图 |
| `reference_video_not_supported` | 400 | 该模型/档位/分辨率不支持参考视频续写 |
| `invalid_reference_video` | 400 | `referenceVideos` 中某一条无法读取，或不符合该模型的单条限制。请读取 `capabilities.video.referenceVideo`：Seedance 2.5 单条 2–30 秒、≤200MB；Seedance 2.0 单条 2–15 秒、≤50MB；每一项都必须是 `https://images.meigen.ai/...` 地址 —— 任意公网 URL 会在这里被拒 |
| `too_many_reference_videos` | 400 | `referenceVideos` 条数超过该模型上限 —— 读 `capabilities.video.referenceVideo.maxCount`（Seedance 2.5 为 10，Seedance 2.0 为 3）|
| `reference_video_total_seconds_exceeded` | 400 | 各条参考视频单独合规，但时长总和超过 `capabilities.video.referenceVideo.maxTotalSeconds`（Seedance 2.5 为 30 秒，Seedance 2.0 为 15 秒）|
| `reference_audio_not_supported` | 400 | 该模型不接受 `referenceAudios` —— 读 `capabilities.video.referenceAudio.enabled` |
| `invalid_reference_audio` | 400 | `referenceAudios` 中某一条不是 `https://images.meigen.ai/...` 地址、无法读取、不是 wav / mp3、超过 15MB，或单条时长越界（Seedance 2.5 为 2–30 秒，Seedance 2.0 为 2–15 秒）|
| `too_many_reference_audios` | 400 | `referenceAudios` 条数超过该模型上限 —— 读 `capabilities.video.referenceAudio.maxCount`（Seedance 2.5 为 10，Seedance 2.0 为 3）|
| `reference_audio_total_seconds_exceeded` | 400 | 参考音频时长总和超过 `capabilities.video.referenceAudio.maxTotalSeconds`（Seedance 2.5 为 30 秒，Seedance 2.0 为 15 秒）|
| `reference_audio_requires_visual` | 400 | 该模型不能只靠音频生成 —— `referenceAudios` 必须搭配至少 1 张参考图或 1 条参考视频（Seedance 2.0；见 `capabilities.video.referenceAudio.requiresVisualReference`）|
| `reference_probe_timeout` | 503 | 参考视频或参考音频在预算内没能完成服务端校验（CDN 抖动、源站变慢等）。**未扣点**，响应体带 `retryable: true` —— 用同一个 `requestId` / `idempotencyKey` 原样重试这条请求，不要另建新尝试 |
| `invalid_input` | 400 | JSON 请求体格式错误，或同时传了 `referenceVideo` 与 `referenceVideos` 但第一条不一致 |
| `invalid_reference_url` | 400 | `referenceImages` 中存在不合法的 URL 或 base64 值 |
| `frame_reference_limit` | 400 | `referenceMode: "frame"` 最多 2 张图，改用 `referenceMode: "content"` 可传更多 |
| `too_many_references` | 400 | 参考图数量超出该模型上限 |
| `too_many_characters` | 400 | 每次生成最多引用 3 个 `[character:...]` |
| `character_not_found` | 400 | 该角色不存在或不属于当前账号 |
| `characters_not_supported` | 400 | 该模型不支持角色引用 |
| `character_tier_required` | 400 | 该角色需要更高档位 |
| `model_not_available` | 403 | 该模型在当前平台不可用 |
| `idempotency_conflict` | 409 | 这个 `idempotencyKey` 已经属于一次参数不同的请求。不要自动换 key 绕过：先用 `GET /api/generate/v2/requests/{requestId}` 查回原请求并核对参数；只有调用方明确要再发起一次付费生成时才用新 key |

除上述之外的错误——包括所有 `5xx` 响应——都代表服务端暂时不可用。稍后重试即可，生成失败的积分会自动退还。

不带 `code` 的错误（如比例不被支持）请按状态码与 `error` 文案处理。

```json
// 400 — 比例不被该模型支持
{
  "success": false,
  "error": "Aspect ratio 32:9 is not supported by GPT Image 2.0",
  "supportedRatios": ["1:1", "1:3", "16:9", "2:3", "21:9", "3:1", "3:2", "3:4", "4:3", "4:5", "5:4", "9:16", "9:21"]
}

// 400 — 参考图不可用
{
  "success": false,
  "code": "invalid_reference_url",
  "error": "Reference images must be public HTTP(S) URLs or data:image/*;base64 inline data. Local file paths (e.g. C:/Users/...) and file:// URIs are not supported — upload the file to a public URL or pass base64 inline.",
  "received": "C:/Users/me/ref.png"
}

// 402 — 高级模型，且无购买积分
{
  "success": false,
  "code": "premium_model_paywall",
  "error": "Premium model requires purchased credits",
  "required": 10,
  "available": 4
}
```
