**技能广场**是一组面向电商场景的引导式工作流 — 与通用[图片和视频生成](/zh/features/generate)并列的独立入口。不需要从零写提示词，按你的场景填一份简短表单，MeiGen 直接产出成品。

网页版从侧边栏、iOS/Android App 从创作页打开**技能广场**查看可用技能。每个技能都有示例项目，动手前可先预览效果。

<Note>
  本页介绍 Web/App 界面。自动化接入请读[五项 Skills API 指南](/zh/api-reference/skills/overview)或 [MCP](/zh/mcp/overview)。API 参数与计费不同：只用购买积分，不提供免费次数；支持图片增强，暂不开放视频增强和 AI 扩图。
</Note>

## 商品详情图

一张实拍图 → 整套商详页图片，用于电商平台的商品详情展示。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 商品图 | 必填 |
| 商品名 | 必填 |
| 卖点文案 | 可选 — 留空由 AI 从商品图中提取 |
| 目标平台 | 影响版式与风格约定 |
| 尺寸比例 | 输出图片的比例 |

**可选内容模块** — 选择要生成的内容板块：

主图 Banner · 参数规格 · 细节特写 · 场景图 · 模特图 · 尺寸图 · 材质 · 使用方法 · 品牌收尾

## 白底图

随手拍的商品照片 → 干净的白底商品图。

**要填：**

- 商品图（必填）

## 营销海报

一句话 → 促销、活动或招聘海报。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 主题 | 一句话描述海报内容 |
| 文案 | 海报上要出现的文字 |
| 额外要求 | 自由文本，可选 |
| 参考图 | 可选 — 可传自有品牌资产 |
| 海报文字语言 | 中文、英文、韩语、日语、俄语、法语、西班牙语 |

## 图片增强（Upscale）

使用原始静态 JPEG、PNG 或 WebP。**Crisp** 保留结构，**Creative** 会重建细节，外观可能变化。开始前查看显示价格和缩图提示；大图可能需要先缩小，因此输出可能小于原图。

支持本地 Upscale 上传准备的 App 版本接受最多 **64 MiB / 6400 万像素**的原图，并将上传文件处理到 **10 MiB**以内。净化后的图片已符合上传限制时不解码像素；否则使用原生尺寸受限解码和压缩。超大尺寸缩小仍需确认，PNG 拍平背景需另行确认。服务端在生成前再次检查真实图片。新的本地 Upscale 上传会先移除 EXIF/GPS/XMP，再生成公开图片链接，同时保留图片方向和颜色配置。当前安装的 App 若不支持这些确认，请使用 Web 界面。App 更新与本次 API/MCP 更新独立发布。MCP 和 HTTP 的限制请查独立的[图片增强 API 指南](/zh/api-reference/skills/upscale)。

## 结果去向

技能生成的结果会进入你常规的[生成历史](/zh/features/generate#生成历史)，与其他生成一起管理 — 同样可以收藏，也可以[发布到广场](/zh/features/gallery#把你的作品发布到广场)。

## 积分消耗

这些工作流采用**独立技能定价**，与通用图片生成的价格分开。GPT Image 2.5 配置固定使用 **Sunburst、2K**，由工作流替你选择模型。

| 工作流 | 选项 | 每张生成图积分 |
| --- | --- | --- |
| 商品详情图 | Fast / Pro | 5 / 18 |
| 营销海报 | Fast / Pro | 5 / 18 |
| 白底图（仅纯白模式） | 固定质量 | 5 |

Fast 对应 Standard 质量，Pro 对应 High 质量。整套图片按每张价格乘以生成张数计算。提交前请以工作流显示的总价与可用状态为准；通用 `gpt-image-2.5` API 请求不适用这些技能价格。AI 换背景的智能或自定义模式使用其他模型，以界面显示价格为准。其他技能也可能采用不同模型与定价。

通用生成价格见[模型对比页](https://www.meigen.ai/model-comparison)。
