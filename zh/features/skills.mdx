**技能广场**是一组面向电商场景的引导式工作流 — 与通用[图片和视频生成](/zh/features/generate)并列的独立入口。不需要从零写提示词，按你的场景填一份简短表单，MeiGen 直接产出成品。

网页版从侧边栏、iOS/Android App 从创作页打开**技能广场**查看可用技能。每个技能都有示例项目，动手前可先预览效果。

<Note>
  本页介绍 Web/App 界面。自动化接入请读[五项 Skills API 指南](/zh/api-reference/skills/overview)或 [MCP](/zh/mcp/overview)。API 参数与计费不同：只用购买积分，不提供免费次数；支持图片增强，暂不开放视频增强和 AI 扩图。
</Note>

## 商品详情图

一张实拍图 → 整套商详页图片，用于电商平台的商品详情展示。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 商品图 | 必填 |
| 商品名 | 必填 |
| 卖点文案 | 可选 — 留空由 AI 从商品图中提取 |
| 目标平台 | 影响版式与风格约定 |
| 尺寸比例 | 输出图片的比例 |

**可选内容模块** — 选择要生成的内容板块：

主图 Banner · 参数规格 · 细节特写 · 场景图 · 模特图 · 尺寸图 · 材质 · 使用方法 · 品牌收尾

## 白底图

随手拍的商品照片 → 干净的白底商品图。

**要填：**

- 商品图（必填）

## 营销海报

一句话 → 促销、活动或招聘海报。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 主题 | 一句话描述海报内容 |
| 文案 | 海报上要出现的文字 |
| 额外要求 | 自由文本，可选 |
| 参考图 | 可选 — 可传自有品牌资产 |
| 海报文字语言 | 中文、英文、韩语、日语、俄语、法语、西班牙语 |

## 图片增强（Upscale）

使用原始静态 JPEG、PNG 或 WebP。**Crisp** 保留结构，**Creative** 会重建细节，外观可能变化。开始前查看显示价格和缩图提示；大图可能需要先缩小，因此输出可能小于原图。

在支持图片增强的 App 版本中，原图不可超过 **64 MiB 或 6,400 万像素**。缩小图片尺寸或将透明 PNG 转为不透明图片前，App 会请你确认。本地上传会移除位置等照片元数据，并保留图片方向和颜色。如果看不到这些选项，请使用网页版。通过接口调用时，请看[图片增强 API 指南](/zh/api-reference/skills/upscale)。

## 视频增强（Upscale）

在 Web/App 的 **Skills → Upscale** 中选择视频，或从视频生成结果的增强菜单进入。仅消耗购买积分，每日免费积分不可用。自动重试不会增加已确认的费用。

| 输出档位 | 每秒积分 | 源视频时长上限 |
| --- | --- | --- |
| 1080P | **7** | 90 秒 |
| 4K | **20** | 30 秒 |

文件最大 **500 MB**。按服务端核验的源视频时长向上取整至整秒计费，以所选档位上限为限；提交前以显示的总价为准。例如，**5.2 秒**源视频按 **6 秒**计费：1080P 为 **42 积分**，4K 为 **120 积分**。处理时间随片长和排队情况变化，可在生成历史中查看进度与结果。

视频增强仅在 Web/App 界面提供，尚未开放给公共 Skills API 或 MCP；`upscale_image` 仍仅处理静态图片。

## 结果去向

技能生成的结果会进入你常规的[生成历史](/zh/features/generate#生成历史)，与其他生成一起管理 — 同样可以收藏，也可以投稿到公开画廊。

## 积分消耗

这些工作流采用**独立技能定价**，与通用图片生成的价格分开。

| 工作流 | 选项 | 每张生成图积分 |
| --- | --- | --- |
| 商品详情图 | Fast / Pro | 5 / 18 |
| 营销海报 | Fast / Pro | 5 / 18 |
| 白底图（仅纯白模式） | 固定质量 | 5 |

整套图片按单价乘以生成张数计费。不同技能和模式的价格可能不同，请在提交前查看当前工作流显示的总价。

通用生成价格见[模型对比页](https://www.meigen.ai/model-comparison)。
