**技能广场**是一组面向电商场景的引导式工作流 — 与通用[图片和视频生成](/zh/features/generate)并列的独立入口。不需要从零写提示词，按你的场景填一份简短表单，MeiGen 直接产出成品。

从侧边栏打开**技能广场**查看可用技能。每个技能都有示例项目，动手前可先预览效果。

## 商品详情图

一张实拍图 → 整套商详页图片，用于电商平台的商品详情展示。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 商品图 | 必填 |
| 商品名 | 必填 |
| 卖点文案 | 可选 — 留空由 AI 从商品图中提取 |
| 目标平台 | 影响版式与风格约定 |
| 尺寸比例 | 输出图片的比例 |

**可选内容模块** — 选择要生成的内容板块：

主图 Banner · 参数规格 · 细节特写 · 场景图 · 模特图 · 尺寸图 · 材质 · 使用方法 · 品牌收尾

## 白底图

随手拍的商品照片 → 干净的白底商品图。

**要填：**

- 商品图（必填）
- 指定主体 — 仅在一张图有多个主体时需要；否则 MeiGen 自动识别主商品

## 营销海报

一句话 → 促销、活动或招聘海报。

**要填：**

| 字段 | 说明 |
| --- | --- |
| 主题 | 一句话描述海报内容 |
| 文案 | 海报上要出现的文字 |
| 额外要求 | 自由文本，可选 |
| 参考图 | 可选 — 可传自有品牌资产 |
| 海报文字语言 | 中文、英文、韩语、日语、俄语、法语、西班牙语 |

## 结果去向

技能生成的结果会进入你常规的[生成历史](/zh/features/generate#生成历史)，与其他生成一起管理 — 同样可以收藏，也可以[发布到广场](/zh/features/gallery#把你的作品发布到广场)。

## 积分消耗

技能与通用生成一样按积分计费 — 消耗多少取决于所选模型与生成张数。当前费率见[模型对比页](https://www.meigen.ai/model-comparison)。
