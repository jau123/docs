MeiGen 让你通过统一的界面使用多种 AI 模型生成图片和视频。桌面端从浮动工具栏打开生成侧边栏；移动端点击底部工具栏的**生成**打开生成浮层。两端提供相同的模型、参考图、`@` 引用、提示词增强、AI 帮改和智能分镜 — 除非某一节另有说明，本指南对两端均适用。

## 模型选择器

在生成侧边栏顶部，模型选择器下拉菜单让你选择要使用的 AI 模型。

每个选项显示：
- **供应商图标** — 模型供应商的视觉标识（Google、ByteDance、Midjourney 等）
- **模型名称** — 模型的显示名称
- **积分消耗** — 该模型每次生成所需的积分

选择不同的模型会自动更新可用的宽高比、分辨率选项和高级设置，以匹配该模型的能力。

## 提示词编辑器

### 编写有效的提示词

- **要具体** — 描述构图、光线、色彩、质感和视角能获得最佳效果
- **简短提示词也可以** — 使用增强按钮自动将简短描述扩展为详细提示词
- **语言** — 大多数模型接受英文提示词。Midjourney V8.1 会自动将非英文提示词翻译为英文

### 变量标签

画廊中的某些提示词包含蓝色的 `[placeholder]` 标签 — 例如 `[style]`、`[subject]` 或 `[color palette]`。这些是**可编辑的模板变量**。

点击任意蓝色标签选中它，然后输入你的替换文字。这让你无需重写整个提示词即可轻松创建变体。

### @ 图片引用

当你上传了多张参考图片时，可以在提示词中内联引用特定图片：

1. 在提示词编辑器中输入 `@`
2. 弹出窗口会显示你已上传的参考图片缩略图
3. 选择一张图片插入引用标签（如 `@image1`、`@image2`）
4. 围绕引用编写指令：*"使用 @image1 作为背景风景，并应用 @image2 的配色方案"*

这让你能精确控制每张参考图片如何影响生成结果。

### 角色

创建一次角色，之后所有生成都能引用它，让同一个人物形象在多张图之间、乃至延伸到视频里保持一致。

1. 点击提示词编辑器上方的**角色**按钮（图片和视频侧边栏均有）
2. 在**创建角色**中填写名称，添加 **1-4 张图片** — 可上传，也可从最近生成的作品中挑选
3. 回到提示词，输入 `@` 选中该角色：*"@小美 站在霓虹灯下的巷子里，电影感光线"*

引用角色后无需再把角色图上传为参考图。在**我的角色**中可重命名或删除；删除后，引用该角色的提示词会失效。

<Tip>
  最佳效果：为角色提供同一角色的竖版全身照 + 无表情面部特写各一张。
</Tip>

<Warning>
  仅允许 AI 生成的人物或虚拟角色。与真实人物相像的图片会被内容审核拒绝。
</Warning>

<Note>
  **配额** — 每个账号能保存的角色总数和每天新建的角色数都有上限，达到上限时弹窗会提示你，可在**我的角色**中删除不用的角色腾出空间。

  **适用范围** — 支持参考图的图片模型（Flux 2 Klein、Z Image Turbo 除外），视频侧为 **Seedance 2.0**。在纯文生图模型上选择角色会直接报错。

  如果把提及角色的作品投稿到公开广场，该角色的主图会随投稿一同公开展示 — 发布确认弹窗会先请你确认。
</Note>

### # 颜色选择

当你想精确描述某个物体的颜色时，可以从色板中快速选取：

1. 在提示词编辑器中输入 `#`
2. 弹出色板，包含常用色和按色相分组的精选色
3. 点击任意色块插入颜色标签（如 `#dc143c`）
4. 围绕颜色编写指令：*"一件 T 恤，颜色是 `#dc143c`，搭配 `#f5f5dc` 的裤子"*

颜色以 hex 值的形式提交给模型，比单纯描述"深红"、"米色"更精确。

### 翻译按钮

点击提示词编辑器右上角的翻译图标，将你的提示词翻译为英文。当你使用其他语言编写提示词时非常有用，因为大多数模型使用英文输入能产生最佳效果。

### 提示词增强

通过**润色提示词**按钮根据当前模型自动增强提示词：

- **润色模式**（大部分模型） — 保留原意，补充构图、光线、材质等视觉细节
- **扩展模式**（Midjourney V8.1） — 扩展为 Midjourney 优化的语言；非英文 prompt 会自动翻译

<CodeGroup>
```text 输入
a cat sitting on a windowsill
```

```text 润色后
A fluffy orange tabby cat sitting gracefully on a sunlit windowsill,
warm golden hour light streaming through sheer curtains, soft bokeh
of a garden visible outside, cozy interior with houseplants, photorealistic
style with shallow depth of field
```
</CodeGroup>

<Tip>
  增强最适合 30 词以下的简短 prompt。已有详细视觉描述的 prompt 可跳过 —— AI 可能过度处理。
</Tip>

### AI 帮改

给 AI 一句修改指令，对现有 prompt 做精准改写 —— 而不是重写整段。

1. 点击提示词编辑器上方的 **AI 帮改** 按钮
2. 描述你想要的改动，例如*"光线改暖一点"*或*"把猫换成狗"*
3. AI 只改这一处，prompt 其余部分保持不变

<Note>
  AI 帮改与[提示词增强](#提示词增强)、智能分镜共享每日额度，不消耗生成积分。
</Note>

| 快捷键 | 操作 |
| --- | --- |
| `Cmd+Enter` / `Ctrl+Enter` | 触发生成 |

## 参考图片

上传参考图片作为视觉上下文来引导 AI 的输出 — 用于风格匹配、构图引导或主题参考。

- **上传方式** — 拖拽文件到参考区域，或点击浏览
- **支持格式** — JPG、PNG、WebP
- **自动压缩** — 图片在上传前自动压缩至最大 2MB / 2048px
- **原图尺寸上限** — 宽或高任一边超过 **8000 像素**的图片会在上传前被拒绝，并提示你先缩小尺寸。日常文件都远在这个限制内：4K 照片长边 3840px，A4 300dpi 扫描件 2480×3508。只有印刷级源文件（大幅面展架、按印刷分辨率制作的海报稿）才会撞上 —— 请先缩小尺寸再上传
- **缩略图网格** — 上传的图片显示为缩略图，带有 × 按钮用于移除
- **各模型限制** — 参考图片的最大数量因模型而异（0-10 张，其中 Seedream 5.0 Pro 最多可传 10 张）。不支持参考图片的模型（Flux 2 Klein 和 Z Image Turbo）会完全隐藏此区域。

<Note>
  查看[模型](/zh/features/models)页面了解每个模型的参考图片数量限制。
</Note>

### 从画廊添加参考

你无需先下载图片。直接将任意画廊卡片拖入参考图片区域 — 图片 URL 会自动使用。

<Tip>
  结合画廊参考和 @ 引用实现强大的多参考工作流。例如，拖入两张画廊卡片作为参考，然后编写："结合 @image1 的构图和 @image2 的配色方案。"
</Tip>

### 参考类型（Midjourney V8.1）

使用 Midjourney V8.1 并添加参考图片时，会出现下拉菜单选择参考的解读方式：

| 类型 | 描述 |
| --- | --- |
| **内容参考** | AI 将图片作为主题素材使用 — 尝试重现类似内容。通过 **Image Weight** (iw) 参数控制影响程度（0-2）。 |
| **风格参考** | AI 提取视觉风格（色彩、氛围、技法），不复制内容。通过 **Style Weight** (sw, 0-1000) 控制。 |

### 何时使用参考图片

某些提示词在配合参考图片时效果最佳，甚至必须搭配参考图才有意义。平台会自动检测提示词中的关键词（如"参考图"、"uploaded image"、"reference image"），并在未上传参考图时显示提醒。

**常见需要参考图的提示词模式：**

| 提示词模式 | 为何需要参考图 |
| --- | --- |
| "将这张参考图转换为..." | AI 需要一张源图进行转换 |
| "基于上传的图片，创建..." | 明确引用了上传的图片 |
| "保持 @image1 的构图，但改变..." | 使用 @ 引用语法引用上传图 |
| "重绘/重新想象参考照片..." | 需要源图来进行重绘 |

<Tip>
  如果你的提示词涉及变换、重绘或引用某张具体图片，请务必先上传该图片作为参考。否则 AI 生成的结果将与你的意图无关。
</Tip>

## 生成选项

### 数量

选择每次请求生成的图片数量（1-4 张）。

- **免费用户** — 每次请求限 1 张图片。+ 按钮上会显示锁定图标。
- **付费用户** — 每次请求最多可并行生成 4 张图片。

### 宽高比

默认为 **Auto** — 无需手动选择，系统会挑一个合适的比例。想要精确控制时从下拉中选具体比例即可。

| 比例 | 方向 | 常见用途 |
| --- | --- | --- |
| **Auto**（默认）| — | 免手动 |
| 1:1 | 正方形 | 社交媒体头像、图标 |
| 3:4, 4:5, 2:3 | 竖向 | 手机壁纸、海报 |
| 9:16 | 高竖向 | Stories、Reels |
| 9:21 | 超高竖向 | 竖版长幅横幅（GPT Image 2.0、Z Image Turbo） |
| 1:3 | 超高竖向 | 竖版长幅横幅（仅 GPT Image 2.0） |
| 1:4, 1:8 | 超高竖向 | 滚动横幅（仅 Nanobanana 2） |
| 4:3, 3:2 | 横向 | 桌面壁纸 |
| 16:9, 21:9 | 宽幅 | 电影画面、超宽屏 |
| 3:1 | 超宽幅 | 页头横幅（仅 GPT Image 2.0） |
| 4:1, 8:1 | 超宽幅 | 全景横幅（仅 Nanobanana 2） |

<Warning>
  并非所有模型都支持所有比例。选择器会自动筛选，仅显示当前模型支持的比例。查看[模型](/zh/features/models)页面了解每个模型支持的比例。
</Warning>

### 分辨率

可选分辨率由所选模型决定，选择器只会给出该模型支持的档位：

| 模型 | 可选分辨率 |
| --- | --- |
| Nanobanana 2、Nanobanana Pro、Seedream 4.5 | 2K / 4K（默认 2K） |
| GPT Image 2.0 | 1K / 2K / 4K（默认 2K） |
| Grok Imagine Image 2.0、Midjourney V8.1、Seedream 5.0 Pro | 1K / 2K（默认 1K） |
| Seedream 5.0 Lite | 2K / 3K |
| Flux 2 Klein、Z Image Turbo、Agnes Image 2.1 Flash | 固定分辨率，不显示选择器 |

<Note>
  **每个模型的最高一档为付费专属**，免费用户会看到锁定图标。即 1K / 2K 的模型锁 2K；2K / 4K 的模型锁 4K；2K / 3K 的模型锁 3K。视频侧同理适用于 4k（Seedance 2.0 Pro 与 Veo 3.1）。
</Note>

## Midjourney V8.1 高级选项

使用 Midjourney V8.1 时，可通过**高级选项**按钮自定义更多生图参数。**大部分用户保持默认即可**。

<Accordion title="参数详情（Stylize / Chaos / Raw / iw / sref / sw）" icon="sliders">

| 参数 | 范围 | 默认值 | 描述 |
| --- | --- | --- | --- |
| **Stylize** | 0-1000 | 100 | 控制 Midjourney 美学风格的应用强度。值越低越写实，值越高越艺术。 |
| **Chaos** | 0-100 | 5 | 增加多次运行间的变化。值越高结果越出乎意料。 |
| **Raw Mode** | 开/关 | 关 | 开启时生成更原始、更少后处理感的图片；关闭时应用模型默认的风格化。 |
| **Image Weight (iw)** | 0-2 | 1 | 内容参考图片的影响程度。仅在设置了内容参考时可见。 |
| **Style Reference (sref)** | URL/文本 | — | 提供一个你想模仿其风格的图片 URL。当参考图片设为风格模式时禁用。 |
| **Style Weight (sw)** | 0-1000 | 100 | 风格参考的应用强度。仅在有 sref 或风格参考图片时可见。 |

</Accordion>

## 反推提示词

看到喜欢的图片但不知道如何描述？**反推提示词**使用 AI 视觉分析图片，生成捕捉其内容、风格和构图的详细文字提示词。

### 使用方法

1. **图片详情对话框** — 打开任意图片的详情视图，点击**反推提示词**按钮。AI 分析图片并生成描述性提示词。
2. **拖放** — 将任意外部图片（或画廊卡片）拖到生成侧边栏提示词编辑器上方的**反推提示词投放区**。

### 生成内容

AI 检查图片并生成描述以下内容的提示词：

- 主题和场景构图
- 艺术风格和技法（写实、插画、水彩等）
- 光线、配色方案和氛围
- 相机角度和视角

你可以直接使用生成的提示词，也可以编辑它来创建原始图片的变体。

<Tip>
  反推提示词非常适合作为起点。可以与[提示词增强](#提示词增强)结合 — 先对喜欢的图片做反推提示词，然后增强结果以获得更多细节。
</Tip>

## 视频生成

MeiGen 支持多个视频模型，完整列表与规格见[模型](/zh/features/models)页面：

- **Seedance 2.5** — 单一质量档，按秒计费，4–30 秒，参考视频最长 30 秒 / 200MB
- **Seedance 2.0** — 三档位，按秒计费，4–15 秒，参考视频最长 15 秒 / 50MB
- **Veo 3.1** — 双档位，按次计费，4 / 6 / 8 秒可选，强制带音频
- **Grok Video 1.5** — 按秒计费，4-15 秒可调，必须上传首帧图
- **Agnes Video 2.0** — 按秒计费，固定 5 秒，每日免费积分可用

桌面端通过浮动工具栏的**生成视频**按钮打开视频侧边栏，移动端点击底部工具栏的**生成**。

### 智能分镜 — 视频提示词生成器

点击视频侧边栏的**智能分镜**，可把一句简短想法扩展成可直接使用的视频提示词：先给出视觉总览，再生成带时间轴的逐镜头安排。请先选择输出时长；分镜会完整覆盖这段时长，并可加入运镜、台词和音效提示。

<Note>
  智能分镜会保持你的输入语言 —— 用任何语言写想法,分镜就用同一种语言返回。它需要登录,并与其他提示词工具共享每日 AI 辅助额度,但**不消耗**图片/视频生成积分。
</Note>

### 帧图片

上传帧图片来控制视频的构图：

- **首帧** — 设置视频的起始构图
- **末帧** — 设置视频的结束构图

**Seedance 2.5**、**Seedance 2.0** 和 **Veo 3.1** 支持首帧 + 末帧（最多 2 张）；**Grok Video 1.5**、**Agnes Video 2.0** 仅支持首帧。

帧图片均为可选，**Grok Video 1.5** 例外 — 它只支持图生视频，首帧为必填，且输出比例跟随该图片。

你也可以直接拖入画廊卡片作为帧图片。

### Seedance 2.5

| 选项 | 可选值 | 描述 |
| --- | --- | --- |
| **宽高比** | adaptive, 16:9, 4:3, 1:1, 3:4, 9:16, 21:9 | 帧图片和参考视频请求使用 `adaptive`；文生视频和内容参考图可选择明确比例 |
| **分辨率** | 480p、720p（默认 480p）| 无质量档位；480p 更省积分 |
| **视频时长** | 4–30 秒（默认 4 秒）| 滑块或输入框选择 |
| **音频** | 自动生成 | 不可关闭 |
| **参考图片** | 最多 2 张 | 首帧/末帧或内容参考 |
| **参考视频** | 2–30 秒、最大 200MB | 系统自动识别真实时长 |

**计费**：直接生成 480p 为 18 积分/秒，720p 为 39 积分/秒；带参考视频时分别为 11 和 24 积分/秒，并应用最低计费秒数。侧边栏会显示精确总积分，公式和示例见[模型 → Seedance 2.5](/zh/features/models)。

Seedance 2.5 没有 Mini / Fast / Pro 切换；明确需要 1080p 或 4K 时请使用 Seedance 2.0 Pro。

### Seedance 2.0

| 选项 | 可选值 | 描述 |
| --- | --- | --- |
| **宽高比** | adaptive, 16:9, 4:3, 1:1, 3:4, 9:16, 21:9 | 7 种比例。`adaptive` 会根据参考图/参考视频自动适配尺寸 |
| **分辨率** | Mini / Fast：480p、720p；Pro：480p、720p、1080p、4K（默认 480p） | 取决于所选档位；480p 更省积分 |
| **视频时长** | 4-15 秒（默认 4 秒） | 滑块或输入框选择 |
| **音频** | 自动生成 | 不可关 |
| **参考视频** | 支持 | 用作"视频续写"的视觉条件输入 —— 须 2-15 秒、不超过 50MB；系统自动识别真实时长（详见下方[续写视频](#续写视频)章节）|

**计费**：按秒计费，详细公式（含参考视频时的最低计费表）见[模型](/zh/features/models)。提交前侧边栏会显示精确的总积分。

**三种模式**：
- 文生视频：只写 prompt
- 图生视频：上传 1-2 张帧图片控制首帧/末帧
- 视频续写：上传参考视频（详见下方[续写视频](#续写视频)章节）

<Warning>
  **带参考视频时总积分受参考视频时长影响**：计费秒数按"参考视频时长 + 你选的 duration"计算（不低于最低计费秒数）。参考视频越长，总积分越高。提交前侧边栏会显示精确的总积分，请确认后再点生成。
</Warning>

### Veo 3.1 — 双档位、原生音频

| 选项 | 可选值 | 描述 |
| --- | --- | --- |
| **档位** | Fast(默认)/ Pro | 在模型选择器下方的切换器中选择 |
| **宽高比** | Auto, 16:9, 9:16 | 仅横版或竖版;Auto 根据 prompt 或参考图推断 |
| **分辨率** | 720p / 1080p / 4k(默认 1080p) | 三档同价,4k 渲染时间更长 |
| **视频时长** | 4 / 6 / 8 秒(默认 4 秒) | 下拉列表选择 |
| **音频** | 自动生成 | 强制开启 |

**计费**:按次计费,价格取决于档位 × 时长。完整价格表见[模型 → Veo 3.1](/zh/features/models)。

<Note>
  所有视频模型的完整规格与横向对比见[模型](/zh/features/models)页面。
</Note>

### 将图片转为视频

生成图片后，将鼠标悬停在完成的卡片上，点击**生成视频**按钮。这会将生成的图片发送到视频侧边栏作为首帧，让你轻松将静态图片转为短视频片段。

### 续写视频

Seedance 2.5 和 Seedance 2.0 都支持参考视频续写。上传一段视频作为视觉条件输入，引导模型生成一段语义上接续原视频的新片段。

<Note>
  **Seedance 2.5**：参考视频 2–30 秒、最大 200MB；输出 4–30 秒，支持 480p / 720p。

  **Seedance 2.0**：参考视频 2–15 秒、最大 50MB；输出 4–15 秒。Mini / Fast 支持 480p / 720p；Pro 续写支持 720p / 1080p。4K 仅限直接生成。

  系统会自动识别上传视频的真实时长用于计费与裁剪。
</Note>

#### 三种入口

1. **从视频卡片**：鼠标悬停在任意完成的视频卡片上，点左上角的**续写**按钮 — 该视频会自动载入 Seedance 侧边栏作为参考视频
2. **拖视频到参考图模块**：拖一段视频（本地或画廊）到参考图上传区，会弹窗询问"用作续写参考？"
3. **直接上传**：在 Seedance 侧边栏的"Extend or reference video"上传区选择本地视频

#### 工作流

1. 触发上述任一入口，参考视频会出现在侧边栏预览区
2. Prompt 框会自动预填 `"Extend this video with the following plot: "` — 在后面补你想要的剧情
3. 按当前 Seedance 模型选择受支持的分辨率和输出时长
4. 点生成

#### 关键行为

<Warning>
  **Prompt 必须明确说"extend / 续写"**：如果 prompt 里只描述场景而不提续写意图，生成的新片段可能跟你预想的"延续"完全不沾边（画面虽会受参考视频影响，但情节方向取决于 prompt 描述）。侧边栏自动预填的 `Extend this video with the following plot: ` 前缀就是为了引导模型走"延续"语义，请保留它再补内容。
</Warning>

<Note>
  **输出长度 = 你设的 duration**（Seedance 2.5 为 4–30 秒；Seedance 2.0 为 4–15 秒），与参考视频时长无关。参考视频只作为视觉条件，不会被拼接进输出。若要得到“原视频 + 新片段”，需用视频编辑工具自行拼接。
</Note>

#### 计费

两个模型都按 `max(参考视频时长 + 输出时长, 最低计费秒数)` 计算。

- **Seedance 2.5**：480p 11 积分/秒，720p 24 积分/秒。2 秒参考 + 5 秒输出按 9 秒计费，共 **99 / 216 积分**。
- **Seedance 2.0**：单价取决于 Mini / Fast / Pro 与分辨率，完整矩阵见[模型 → Seedance 2.0](/zh/features/models)。

## 积分和计费

MeiGen 采用双积分制：

- **每日积分**：每天赠送的免费额度，UTC 00:00 重置，用于**基础模型** — 当前图片侧为 **Z Image Turbo**、**Flux 2 Klein**、**Agnes Image 2.1 Flash**，视频侧为 **Agnes Video 2.0**（唯一被每日积分覆盖的视频模型）。它们在模型选择器里归在 **Basic Models** 分组下。
- **购买积分**：侧边栏「Credits」那一行显示的永不过期余额。除每日免费额度外的积分都记在这里 — 包括充值获得的，以及发放到账户的赠送积分（注册赠送、推荐奖励）。可用于所有模型。

生成高级模型（GPT Image 2.0、Nanobanana 2 / Pro、Seedream、Midjourney V8.1、Grok Imagine Image 2.0、Seedance 2.5 / 2.0、Veo 3.1、Grok Video 1.5 等）需要消耗赠送积分或购买积分 — 无论是否付过费，每日积分都不能用于高级模型。

**API Token 调用**只使用购买积分，不论调用哪个模型；每日积分在 API 路径永远不参与扣费。

积分消耗会在提交前显示在生成按钮上；将鼠标悬停在左侧边栏底部的积分卡片可查看余额明细。

### 免费 vs 付费

| 功能 | 免费用户 | 付费用户 |
| --- | --- | --- |
| 各模型最高一档分辨率 | 锁定 | 可用 |
| 每次请求图片数（Web 界面）| 1 | 最多 4 |
| API 访问 | 可用（仅购买积分）| 可用（仅购买积分） |

> "每次请求图片数"限制仅作用于 Web 界面。API 每次调用始终返回 1 张图片（Midjourney V8.1 例外，每次固定返回 4 张候选）。
>
> 创建 API Token 不需要付费账户，任何账户都可以在「设置 → API Keys」中创建。API 调用真正需要的是购买积分 —— 每日免费积分在 API 路径上永远不参与扣费。

## 常见问题

<AccordionGroup>
  <Accordion title="为什么我的生成时间比预期长？" icon="clock">
    生成时间因模型和服务器负载而异。具体时间参见本节顶部的对比表。
  </Accordion>

  <Accordion title="生成失败了 — 我的积分怎么办？" icon="coins">
    生成失败时积分会自动退还。退款会立即反映在你的余额中。你可以使用重试按钮再次尝试。
  </Accordion>

  <Accordion title="我能再次生成同一张图片吗？" icon="repeat">
    在失败的卡片上使用**重试**按钮，或在已完成的卡片上点击**使用创意**将提示词复制回编辑器。请注意，AI 生成是非确定性的 — 即使使用相同的提示词，结果也会有所不同。
  </Accordion>

  <Accordion title="抠图和生成视频有什么区别？" icon="scissors">
    **抠图**移除静态图片的背景，创建透明 PNG。**生成视频**使用视频生成模型将静态图片转为短视频片段。
  </Accordion>

  <Accordion title="为什么分辨率选择器显示锁定图标？" icon="lock">
    每个模型的最高一档分辨率仅付费用户可用：2K / 4K 的模型锁 4K，Seedream 5.0 Lite 锁 3K，1K / 2K 的模型锁 2K。升级你的账户即可解锁。
  </Accordion>
</AccordionGroup>
