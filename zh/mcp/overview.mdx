在 ChatGPT 中使用 MeiGen，或[连接你的 MCP 客户端](/zh/mcp/remote)。维护已有本地 npm 集成或使用自己的生图 API Key，请看[本地配置](/zh/mcp/setup)。

## ChatGPT

1. 打开 [ChatGPT 官方商店中的 MeiGen](https://chatgpt.com/plugins/plugin_asdk_app_6ab66d24f56481919361b6c33f7c1928)，选择 **Install**。
2. 登录 MeiGen 账号并完成连接，无需 API Key 或 Node.js。
3. 在对话中选择或提及 **MeiGen**，让它搜索灵感，或创建图片和视频。

用 `search_gallery` 查找画廊作品，搜索计入账号的搜索额度。生成图片和视频使用充值积分，提交前可用 `list_models` 查看可用模型和价格。

工具名称及权限见[工具清单](/zh/mcp/remote#工具)。制作抠图、海报等作品时，可用 `list_skills` 查询所需素材和价格。另见[图片工作流参数](/zh/api-reference/skills/overview)、[视频草稿](/zh/mcp/drafts)和[中断后恢复任务](/zh/mcp/composable-workflows)。
