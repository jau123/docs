**MeiGen** 是一个开源的 MCP (Model Context Protocol) 服务器，赋予 AI 编程助手生成**图片和视频**的能力。它支持多种生成后端 — 使用 MeiGen 的云端模型、你本地的 ComfyUI 服务器，或任何 OpenAI 兼容 API。

## 作为上层工作流的工具

保留上层脚本、提示词、模型／供应商、数量和已批准预算，创意助手可选。使用持久化 UUID `requestId`、`wait: false`、结构化结果及 `check_generation` 提交首帧／视频并恢复，无需逐步重复审批。有限并发调度、预览和下载由上层负责。详见[完整工作流合同与示例](/zh/mcp/composable-workflows)。

## 什么是 MCP？

Model Context Protocol (MCP) 是一个开放标准，允许 AI 助手使用外部工具。当你将 MeiGen 安装为 MCP 服务器后，你的 AI 助手就能通过自然语言生成图片和视频、对 MeiGen 社区提示词画廊做语义搜索、增强提示词。搜索、灵感和提示词增强无需 API Key；本地 npm 包内置提示词库，可作离线搜索回退；远程连接需要网络。

## 五项专用图片工作流

用自然语言要求抠图、商品详情图、营销海报、换背景或图片增强。Agent 应先读取 `list_skills`，准备真实材料，调用对应工具，再用 `check_skill` 查询结果；UUID 由 Agent 自行生成。已经指定的数量和质量就是你的指令，仅未定范围或 Upscale 警告需要进一步决定。

| 工作流 | 必需材料 | 可选材料 | 输出 |
| --- | --- | --- | --- |
| 透明抠图 | 一张原图 | 无 | 一张透明 PNG |
| 商品详情图 | 一张商品图及已选择的模块/数量 | 商品名、核实的卖点、Logo、模特图、两张额外角度图 | 1–6 张付费图 |
| 营销海报 | 品牌、活动或主题 | 文案、Logo、三张商品图、风格参考图 | 一张付费海报 |
| AI 换背景 | 一张商品图 | 模式；自定义模式必须提供背景描述 | 一张付费图 |
| 图片增强 | 一张原始静态 JPEG/PNG/WebP | 清晰或创意模式 | 一张付费增强图 |

Skills 只用购买积分，不提供免费次数或每日积分。BYOK/ComfyUI 不提供这些工作流。详见[完整 Skills API 与素材指南](/zh/api-reference/skills/overview)。

海报的画面文案放在 `content`，设计要求放在 `extraNotes` 或 `customStyle`。`autoCopy: false` 忠实使用原文，选定语言仍可要求翻译。参见[海报字段用途与完整 MCP 调用示例](/zh/api-reference/skills/marketing-poster#mcp-调用示例)。

## 选择连接

使用 MeiGen Cloud 优先选择[远程 MCP](/zh/mcp/remote)：无需本地 npm 进程，通过无状态 Streamable HTTP 接入；服务端更新需要后端部署，客户端刷新工具后可用。需要自动读取本地文件、本地偏好、提示词增强或 ComfyUI 时选[本地 npm](/zh/mcp/setup)。Claude 插件的命令、Agent 和 Hook 是独立分发的附加功能，添加远程 URL 不会安装它们。

## 提供商

MeiGen 支持三种图片生成后端 —— 可配置一个或多个。

<CardGroup cols={3}>
  <Card title="MeiGen Cloud" icon="cloud">
    **托管式多模型 API**。汇集 OpenAI、Google、ByteDance、Midjourney、xAI、Black Forest Labs、Alibaba、Agnes 的图像与视频模型。无需 GPU — 只需一个 API Key。当前清单随时用 `list_models` 查。
  </Card>
  <Card title="ComfyUI" icon="server">
    **本地 GPU 生成**。在你自己的硬件上运行任何 Stable Diffusion、SDXL 或 Flux 模型。完全控制工作流和参数。
  </Card>
  <Card title="自带 API" icon="plug">
    **任意 OpenAI 兼容 API**。接入 Together AI、Fireworks AI、DeepInfra、硅基流动、OpenAI，或你自己的端点。
  </Card>
</CardGroup>

| 提供商 | 类型 | 费用 | 适用场景 |
| --- | --- | --- | --- |
| MeiGen Cloud | 托管 API | 积分（[定价](/zh/features/models)） | 多模型访问，零配置 |
| ComfyUI | 本地 GPU | 免费（使用你自己的硬件） | 完全控制，自定义工作流，隐私保护 |
| 自带 API | OpenAI 兼容 | 因服务而异 | 已有 API Key，任意供应商 |

**提供商优先级**：当配置了多个提供商时，MeiGen 按以下顺序选择：MeiGen Cloud → ComfyUI → OpenAI 兼容。你可以在每次请求时覆盖此设置。

## 工具

远程 Streamable HTTP 提供 **14 个工具**，本地 npm 提供 **17 个工具**。以下 14 个工具两种连接都有：

| 工具 | 用途 | MeiGen Key |
| --- | --- | --- |
| `generate_image` | 通用图片生成，本地可使用已配置的后端 | MeiGen Cloud 需要 |
| `generate_video` | MeiGen Cloud 视频生成 | 是 |
| `check_generation` | 按 generationId 或 requestId 查询／恢复 | 按请求 ID 查询需要同账号 Key |
| `list_models` | 当前模型与能力 | 否 |
| `search_gallery` | 搜索公开提示词和图片预览，最多返回 3 条 | 否 —— 但带 Key 时该次搜索计入这个账户的额度 |
| `get_inspiration` | 读取公开画廊条目 | 否 |
| `list_skills` | 五项工作流、材料、实时价格和输入参数 | 否 |
| `upload_skill_image` | 准备真实图片 URL 或附件字节 | 是 |
| `remove_background` | 一张透明抠图 | 是 |
| `generate_product_detail_images` | 1–6 张付费商品模块图 | 是 |
| `generate_marketing_poster` | 一张营销海报 | 是 |
| `generate_ai_background` | 一张纯白、智能或自定义背景图 | 是 |
| `upscale_image` | 增强一张原始静态图片 | 是 |
| `check_skill` | 私有 Skill 回执、模块状态和恢复 | 是，同一个Key |

本地另有 `enhance_prompt`、`manage_preferences`、`comfyui_workflow`，它们不要求 MeiGen Key。本地画廊搜索可回退到内置提示词库，远程访问需要网络。两种连接下 `search_gallery` 每次都**最多返回 3 条**；配置了 Key 时（本地为 `MEIGEN_API_TOKEN`，远程为 `Authorization` 头），每次搜索计入该账户的[**每日搜索额度**](/zh/features/gallery#搜索) —— 与网页登录用户相同的免费额度，不消耗购买积分。没有 Key 时按匿名 IP 限流。多提供商配置适用于通用生成，所有专用 Skill 都需要 MeiGen Cloud 凭据和购买积分。远程 `check_generation` 按已知 generationId 公开查询；按 requestId 恢复需要所属账号的有效 Key。`check_skill` 必须使用原 API Key。

<Note>
  视频能力因模型而异 — 画质档位、可选时长与分辨率、音频、参考视频续写，以及是否必须提供首帧图。部分模型仅支持图生视频。当前清单用 `list_models` 查，或见[模型对比](/zh/features/models)。

  Seedance 2.5 的模型 ID 是 `seedance-2-5`，支持 4–30 秒、480p/720p/1080p 输出和参考视频续写，没有 `tier` 参数。

  `generate_video` 必须显式指定 `model`——平台没有默认模型。参考素材都是数组：`referenceVideos`（mp4 / mov）和 `referenceAudios`（wav / mp3，单条 ≤15MB）。**本地 npm 服务器支持直接传本地文件路径**并自动上传；远程服务器只接受已经指向 `images.meigen.ai` 的地址 —— 此前生成结果的 `videoUrl`，或通过 [`POST /api/upload/reference-video`](/zh/api-reference/endpoint/generate#上传参考视频与音频) 上传的文件。任意公网 URL 会在扣点前被拒。单数形式 `referenceVideo` 仍作为只含一项的别名受理；`referenceVideoDuration` 是已弃用且会被校验的兼容提示，不会决定计费时长 —— 请省略它，服务端会逐条探测。

  各模型上限从 `list_models` 读取（`capabilities.video.referenceVideo` 与 `capabilities.video.referenceAudio`）：Seedance 2.5 最多 10 条视频和 10 条音频，每类单条 2–30 秒、合计 30 秒；Seedance 2.0 各最多 3 条，单条 2–15 秒、合计 15 秒。**Seedance 2.0 不能只靠音频生成** —— 它的参考音频必须搭配至少 1 张参考图或 1 条参考视频；Seedance 2.5 则允许纯音频请求。

  计费按参考视频时长的**总和** + 你的输出时长，且不低于最低计费秒数。参考音频免费：不计入这个总和，只带音频、不带参考视频的请求按该模型的直接生成价计费。
</Note>

### GPT Image 2.5

先调用 `list_models` 确认可用性。本地 npm 服务使用 `model: "gpt-image-2.5"`；支持的版本会把 `quality` 透传给 MeiGen（`low`、`medium`、`high`、`xhigh`、`max`）。本地包目前没有 `modelVariant` 参数，因此使用后端默认 Sunburst。需要显式选择 Flare 时，请用[远程 MCP 服务](/zh/mcp/remote)或 [REST API](/zh/api-reference/endpoint/generate)。GPT Image 2 作为独立模型保留原有价格。

## 独立 CLI 模式

没有 MCP 宿主?MeiGen 同包附带 CLI,适合 shell 脚本和 CI 流水线:

```bash
export MEIGEN_API_TOKEN=meigen_sk_...
npx -y meigen@2.0.2 gen --prompt "阳光厨房里的三花猫"
npx -y meigen@2.0.2 gen -p "logo design" -m midjourney-v8.1 -r 1:1 --json
```

`--json` 输出机器可读、`--no-wait` 仅提交不轮询、`--reference <path|url>` 传参考图。完整参数 `npx -y meigen@2.0.2 gen --help`。
