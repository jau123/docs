**MeiGen** 帮你在常用的 AI 工具中发现灵感，使用最新 AI 模型创建图片和视频。你可以安装 ChatGPT 插件、连接远程 MCP，或使用开源本地服务。

## ChatGPT

1. 打开 [ChatGPT 官方商店中的 MeiGen](https://chatgpt.com/plugins/plugin_asdk_app_6ab66d24f56481919361b6c33f7c1928)，选择 **Install**。
2. 登录 MeiGen 账号并完成连接，无需 API Key 或 Node.js。
3. 在对话中选择或提及 **MeiGen**，让它搜索灵感，或创建图片和视频。

试试：*“用 MeiGen 搜索极简产品摄影灵感，展示参考图片和对应的提示词。”*

搜索不消耗生成积分。生成使用 MeiGen 账号的充值积分，不使用每日免费积分；生成前确认模型、图片数量和总价。

ChatGPT 插件和远程 OAuth 连接使用 MeiGen Cloud。本地 npm 保留已有 MeiGen API Key 集成兼容，以及明确选用的外部供应商 BYOK；3.0.0 已移除 ComfyUI 与内置离线提示词库，详见[迁移说明](/zh/mcp/comfyui)。

## 作为上层工作流的工具

保留上层脚本、提示词、模型／供应商、数量和已批准预算，创意助手可选。使用持久化 UUID `requestId`、`wait: false`、结构化结果及 `check_generation` 提交首帧／视频并恢复，无需逐步重复审批。有限并发调度、预览和下载由上层负责。详见[完整工作流合同与示例](/zh/mcp/composable-workflows)。

## 什么是 MCP？

Model Context Protocol (MCP) 是一个开放标准，允许 AI 助手使用外部工具。当你将 MeiGen 安装为 MCP 服务器后，你的 AI 助手就能通过自然语言生成图片和视频、对 MeiGen 社区提示词画廊做语义搜索、增强提示词。通用远程 MCP 和本地 npm 支持匿名搜索公开灵感；官方 ChatGPT 插件的搜索需要账号授权。提示词增强属于本地工具。3.0.0 的灵感搜索仅访问在线画廊，不再提供离线回退；在线服务不可用会返回错误。

## 五项专用图片工作流

用自然语言要求抠图、商品详情图、营销海报、换背景或图片增强。Agent 应先读取 `list_skills`，准备真实材料，调用对应工具，再用 `check_skill` 查询结果；UUID 由 Agent 自行生成。已经指定的数量和质量就是你的指令，仅未定范围或 Upscale 警告需要进一步决定。

| 工作流 | 必需材料 | 可选材料 | 输出 |
| --- | --- | --- | --- |
| 透明抠图 | 一张原图 | 无 | 一张透明 PNG |
| 商品详情图 | 一张商品图及已选择的模块/数量 | 商品名、核实的卖点、Logo、模特图、两张额外角度图 | 1–6 张付费图 |
| 营销海报 | 品牌、活动或主题 | 文案、Logo、三张商品图、风格参考图 | 一张付费海报 |
| AI 换背景 | 一张商品图 | 模式；自定义模式必须提供背景描述 | 一张付费图 |
| 图片增强 | 一张原始静态 JPEG/PNG/WebP | 清晰或创意模式 | 一张付费增强图 |

Skills 只用购买积分，不提供免费次数或每日积分。BYOK 不提供这些工作流。详见[完整 Skills API 与素材指南](/zh/api-reference/skills/overview)。

海报的画面文案放在 `content`，设计要求放在 `extraNotes` 或 `customStyle`。`autoCopy: false` 忠实使用原文，选定语言仍可要求翻译。参见[海报字段用途与完整 MCP 调用示例](/zh/api-reference/skills/marketing-poster#mcp-调用示例)。

## 选择连接

ChatGPT 用户使用[官方插件](#chatgpt)。其他新用户通过[远程 OAuth](/zh/mcp/remote)连接 `https://www.meigen.ai/api/mcp`，在客户端登录 MeiGen 并授权；无需创建 API Key 或安装 Node.js。不支持 OAuth 时请使用兼容客户端。

[本地 npm](/zh/mcp/setup)保留既有 API Key 的生成、公开搜索和 Skills 兼容，以及 BYOK、本地文件处理、提示词增强和本地偏好。它没有 OAuth 登录，也不提供私人资料库。API Key 不是新用户的另一种认证选项。OpenClaw 用户可[安装 ClawHub 插件并通过 OAuth 连接](/zh/mcp/remote#openclaw)。已有 Claude／OpenClaw 本地连接作为独立兼容路径保留，切换时避免重复工具。

3.0.0 本地普通生图仍支持 MeiGen（已有旧 Key）和 OpenAI 兼容供应商；优先级为 MeiGen → OpenAI 兼容。ComfyUI 不再支持，五项 Skills 与视频仍由 MeiGen 云端提供。模型与价格以 `list_models`、`list_skills` 为准。

## 工具

以下 **16 个共享工具**包含参考视频／音频准备。本地 npm 3.3.0 共 18 个工具，包含两个本地辅助工具。通用远程 MCP 与官方 ChatGPT 适配服务各提供 23 个工具，另有积分余额、已有角色和五个私人资料库工具。更新后需刷新客户端缓存的工具清单，实际可用能力仍取决于客户端及用户批准的权限。

| 工具 | 用途 | MeiGen 账号授权 |
| --- | --- | --- |
| `generate_image` | 通用图片生成，本地可使用已配置的后端 | MeiGen Cloud 需要 |
| `generate_video` | MeiGen Cloud 视频生成，包括主动选择草稿模式 | 是 |
| `render_video_draft` | 从已完成草稿创建另行确认费用的 1080p 成片 | 是 |
| `check_generation` | 按 generationId 或 requestId 查询／恢复 | 按请求 ID 查询需要授权所属账号 |
| `list_models` | 当前模型与能力 | 否 |
| `search_gallery` | 搜索公开提示词和图片预览，各连接的每批上限见下表 | 通用 MCP／本地可选；官方 ChatGPT 插件必须授权 |
| `get_inspiration` | 读取公开画廊条目 | 否 |
| `list_skills` | 五项工作流、材料、实时价格和输入参数 | 否 |
| `upload_skill_image` | 准备真实图片 URL 或附件字节 | 是 |
| `upload_reference_media` | 为指定模型准备选中的视频／音频网址 | 是 |
| `remove_background` | 一张透明抠图 | 是 |
| `generate_product_detail_images` | 1–6 张付费商品模块图 | 是 |
| `generate_marketing_poster` | 一张营销海报 | 是 |
| `generate_ai_background` | 一张纯白、智能或自定义背景图 | 是 |
| `upscale_image` | 增强一张原始静态图片 | 是 |
| `check_skill` | 私有 Skill 回执、模块状态和恢复 | 是，所属账号；旧版本地调用须使用原 Key |

本地另有 `enhance_prompt` 和 `manage_preferences`，均不需要 MeiGen 账号。3.0.0 不再提供 `comfyui_workflow` 或离线提示词回退。

| 公开画廊搜索 | 每批默认／最多条数 | 账号访问 |
| --- | --- | --- |
| 通用远程 MCP | 3／3 | 可选 OAuth；匿名搜索按 IP 限流 |
| 本地 npm 3.3.0 | 3／3 | 匿名，或兼容已有旧版 Key |
| 官方 ChatGPT 插件 | 刷新工具后：6／6 | 必须 OAuth 授权搜索权限（`meigen:search`） |

授权搜索使用账号[每日搜索额度](/zh/features/gallery#搜索)，不消耗生成积分。开始一次搜索计入额度，后续翻页不重复计数。通用远程 MCP 与本地 3.0.0 支持分页；ChatGPT 官方适配服务也提供换批卡片，需客户端加载当前工具。查看同方向下一批时，保留返回的查询词和快照 ID，将 `nextOffset` 传为 `offset`；`hasMore=false` 时停止。换方向则开始新查询。生成请求恢复仍保留原 ID，不能因超时重新创建付费任务。

## Midjourney 参数

通用远程 MCP、官方 ChatGPT 插件，以及使用 MeiGen 供应商的本地 npm **3.3.0 或更高版本**均支持这些 `generate_image` 参数。远程连接请刷新工具清单，本地连接请更新包版本并重启。**Midjourney V8.2** 继续使用稳定模型 ID `midjourney-v8.1`。

| 输入 | 用法 |
| --- | --- |
| `referenceImages` | 用 `upload_skill_image` 准备选中的参考图，传入返回的 URL；本地 npm 也可上传宿主可读取的文件。遵守实时模型参考图上限。 |
| `referenceType` | `content`（默认，内容参考）或 `style`（风格参考）。传入风格参考图时优先于 `niji7Options.sref`；已有角色仍作为内容参考。 |
| `niji7Options` | `stylize`（0–1000）、`chaos`（0–100）、`raw`（布尔值）、`iw`（0–3）、`sref`、`sw`（0–1000）、`profile` 和 MJ `quality`（`"1"` 或 `"4"`）。V8.2 固定使用 `sv=6`，忽略 `weird`。 |
| `resolution` | `1K` 或 `2K`。每次返回 4 张候选图，只收费一次：当前 1K 12 积分、2K 18 积分。提交前按实时 `list_models` 报价。 |

下面是普通 `generate_image` 工具参数示例；实际提交会付费，不能用来验证连接。每个新获准任务都应将示例 `requestId` 换成新的 UUID 并持久保存：

```json
{
  "requestId": "03c08bc1-d158-40af-a667-7ba901788a7f",
  "modelId": "midjourney-v8.1",
  "prompt": "柔和窗光下的一只陶瓷咖啡杯",
  "aspectRatio": "2:3",
  "resolution": "2K",
  "niji7Options": { "stylize": 100, "raw": false, "quality": "4" }
}
```

MJ 画质放在 `niji7Options.quality` 内，顶层 `quality` 是其他图片模型的独立设置。优先使用结构化参数。`sref` 接受数字风格码、`random` 或图片 URL；`profile` 接受以空格或逗号分隔的字母数字档案码。官方 ChatGPT 插件的参考图和图片型 `sref` 仅接受 `images.meigen.ai` 的直接素材 URL，外部图片先上传。通用远程 MCP 和本地 npm 可使用公开 HTTPS 图片作为 `sref`；本地文件路径应放在本地 npm 的 `referenceImages`，不能放进 `sref`。

远程已有角色需现有角色读取权限，并使用 `list_characters` 返回的准确 `referenceToken`；组合输入前检查 `capabilities.characters` 和参考图限制。后端继续处理提示词翻译和超长提示词压缩。恢复任务时保留原 `requestId`、参考图角色和全部参数值，不能改参后复用同一 ID。完整字段见[生成参数说明](/zh/api-reference/endpoint/generate)。

## 通过远程 OAuth 访问私人资料库

通用远程 MCP 提供 `search_favorites`、`list_boards`、`search_history`、`get_library_item` 和 `save_favorite`。通过 OAuth 连接，并在请求时分别同意资料库读取／写入权限；已有连接不会自动获得新权限。本地 npm 和 API Key 不支持这些工具。官方 ChatGPT 适配服务也提供这些能力；看不到时请重新连接或刷新工具。

列表只返回最多 500 个 Unicode 码点的 prompt 摘要。选定作品后用 `get_library_item` 分页读取用户提示词，默认 8000、最多 16000 码点；不返回内部 Skill 提示词。收藏须用户明确要求或事先允许，重复保存不会取消收藏或覆盖备注，只能存入自己的私密画板。收藏是偏好参考，不能代替用户当前要求。


<Note>
  视频能力因模型而异 — 画质档位、可选时长与分辨率、音频、参考视频续写，以及是否必须提供首帧图。部分模型仅支持图生视频。当前清单用 `list_models` 查，或见[模型对比](/zh/features/models)。

  Seedance 2.5 的模型 ID 是 `seedance-2-5`，支持 4–30 秒、480p/720p/1080p 输出和参考视频续写，没有 `tier` 参数。

  `generate_video` 必须明确选择模型。`firstFrame`／`lastFrame` 表示首尾帧，`contentReferenceImages` 表示内容、身份或风格参考；只使用首尾帧时传 `contentReferenceImages: []`。按 `list_models.capabilities.videoInputs` 及档位覆盖设置遵守互斥规则，不要擅自混合首尾帧、内容参考和角色。

  图片使用 `upload_skill_image`；选中的直接 HTTPS 视频／音频网址使用 `upload_reference_media`，随后将返回的 MeiGen URL 放入 `referenceVideos`／`referenceAudios`。官方插件还支持客户端可访问的附件。远程端不能读取本地路径，既有本地 npm 集成仍可准备本地文件。准备素材要求有正数充值余额，但不扣积分。视频／音频链接公开且临时，在上传七天后进入清理范围；应在有效期内复用，不作为永久图床。

  报价以实时 `pricingMode` 和 `capabilities.video.billing` 为准：部分模型计入输入视频和输出秒数，`output_only` 只计输出。音频秒数不额外计费，但支持该规则的模型可能因音频或内容图切换到参考档费率。HeyGen 已开放，参考视频是否可用以实时目录为准。遵守 `capabilities.video.referenceAudio.canCombineWithVideo`：为 false 时，不可同时提交视频与单独音频，视频自带音轨可保留。HeyGen 按输出秒数＋每段参考视频向上取整后的秒数，以参考档单价计费。

</Note>

## 积分余额与已有角色

远程 OAuth 提供 `get_credit_balance`，查询 MCP 可用的充值积分，不包含每日免费积分。`list_characters` 需要单独批准 `meigen:characters:read`，仅读取已有角色。在支持的模型提示词中使用返回的完整 `referenceToken`，先检查 `capabilities.characters`，上传素材的引用格式则以模型 `referenceMentionSyntax` 为准。暂不支持创建角色。本地 npm 和 API Key 不能读取或使用私人角色。

### GPT Image 2.5

先调用 `list_models` 确认可用性。**本地 npm 3.0.0 支持** `model: "gpt-image-2.5"` 或别名 `modelId`、`quality`（`low`、`medium`、`high`、`xhigh`、`max`），以及 `modelVariant: "sunburst"`（默认）或 `"flare"`。同时传入 `model` 和 `modelId` 时两者必须相同。[远程 MCP 服务](/zh/mcp/remote)与 [REST API](/zh/api-reference/endpoint/generate) 使用 `modelId` 搭配 `modelVariant`。GPT Image 2 作为独立模型保留原有价格。
