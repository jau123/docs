**MeiGen** 是一个开源的 MCP (Model Context Protocol) 服务器，赋予 AI 编程助手生成**图片和视频**的能力。它支持多种生成后端 — 使用 MeiGen 的云端模型、你本地的 ComfyUI 服务器，或任何 OpenAI 兼容 API。

  查看源代码、报告问题和贡献代码。
</Card>

## 什么是 MCP？

Model Context Protocol (MCP) 是一个开放标准，允许 AI 助手使用外部工具。当你将 MeiGen 安装为 MCP 服务器后，你的 AI 助手就能通过自然语言生成图片和视频、对 MeiGen 社区提示词画廊做语义搜索、增强提示词。搜索、灵感和提示词增强无需 API Key；插件还内置了一套提示词库，离线时搜索依然可用。

## 提供商

MeiGen 支持三种图片生成后端 —— 可配置一个或多个。

<CardGroup cols={3}>
  <Card title="MeiGen Cloud" icon="cloud">
    **托管式多模型 API**。汇集 OpenAI、Google、ByteDance、Midjourney、xAI、Black Forest Labs、Alibaba、Agnes 的图像与视频模型。无需 GPU — 只需一个 API Key。当前清单随时用 `list_models` 查。
  </Card>
  <Card title="ComfyUI" icon="server">
    **本地 GPU 生成**。在你自己的硬件上运行任何 Stable Diffusion、SDXL 或 Flux 模型。完全控制工作流和参数。
  </Card>
  <Card title="自带 API" icon="plug">
    **任意 OpenAI 兼容 API**。接入 Together AI、Fireworks AI、DeepInfra、硅基流动、OpenAI，或你自己的端点。
  </Card>
</CardGroup>

| 提供商 | 类型 | 费用 | 适用场景 |
| --- | --- | --- | --- |
| MeiGen Cloud | 托管 API | 积分（[定价](/zh/features/models)） | 多模型访问，零配置 |
| ComfyUI | 本地 GPU | 免费（使用你自己的硬件） | 完全控制，自定义工作流，隐私保护 |
| 自带 API | OpenAI 兼容 | 因服务而异 | 已有 API Key，任意供应商 |

**提供商优先级**：当配置了多个提供商时，MeiGen 按以下顺序选择：MeiGen Cloud → ComfyUI → OpenAI 兼容。你可以在每次请求时覆盖此设置。

## 工具

大部分 MCP 工具无需配置提供商即可使用：

| 工具 | 描述 | 需要提供商？ |
| --- | --- | --- |
| **generate_image** | 使用任意已配置的提供商生成图片 | 是 |
| **generate_video** | 通过 MeiGen 平台生成视频 — 支持文生视频、首/末帧图生视频，以及参考视频续写 | 是(MeiGen) |
| **check_generation** | 按 ID 查询异步生成任务的状态 — 连接中断后续查进度，无需重新提交 | 是(MeiGen) |
| **enhance_prompt** | 将简短的想法转化为详细、专业的提示词 | 否 |
| **search_gallery** | 对 MeiGen 社区提示词画廊做语义搜索，带图片预览 — 搜索 API 不可达时回落到插件内置的离线提示词库 | 否 |
| **get_inspiration** | 获取画廊条目的完整提示词和图片 | 否 |
| **list_models** | 列出所有已配置提供商的可用模型 | 否 |
| **manage_preferences** | 保存默认项（风格、宽高比、模型、提供商、自由文本风格备注）以及收藏的提示词 | 否 |
| **comfyui_workflow** | 导入、查看、修改和删除 ComfyUI 工作流模板 | 否 |

<Note>
  视频能力因模型而异 — 画质档位、可选时长与分辨率、音频、参考视频续写，以及是否必须提供首帧图。部分模型仅支持图生视频。当前清单用 `list_models` 查，或见[模型对比](/zh/features/models)。

  Seedance 2.5 的模型 ID 是 `seedance-2-5`，支持 4–30 秒、480p/720p 输出和参考视频续写，没有 `tier` 参数。

  `generate_video` 必须显式指定 `model`——平台没有默认模型。`referenceVideoDuration` 是已弃用且会被校验的兼容提示，不会决定计费时长；请省略它并传 `referenceVideo`，服务端会自动探测真实时长。
</Note>

## 支持的平台

<CardGroup cols={3}>
  <Card title="Claude Code" icon="terminal">
    从插件市场安装 — 包含斜杠命令、智能 Agent 和自动化 Hook。
  </Card>
  <Card title="Cursor / VS Code / Windsurf / Roo Code" icon="window">
    一行命令 `npx meigen init <host>` 为每个编辑器写好 MCP 配置文件。
  </Card>
  <Card title="OpenAI Codex CLI" icon="terminal">
    将 MCP server 加到 `~/.codex/config.toml`。标准 stdio MCP,无额外管道。
  </Card>
  <Card title="Hermes Agent" icon="robot">
    原生支持 MCP — 加到 `~/.hermes/config.yaml`,视频生成需 `timeout: 2700`。
  </Card>
  <Card title="OpenClaw" icon="puzzle-piece">
    从 [ClawHub](https://clawhub.ai/plugins/meigen-ai-design) 安装插件 — 包含技能、命令和 MCP 服务器。
  </Card>
  <Card title="任意 MCP 客户端" icon="plug">
    标准 stdio MCP — 任意 MCP 兼容客户端指向 `npx -y meigen@latest` 即可。
  </Card>
</CardGroup>

## 独立 CLI 模式

没有 MCP 宿主?MeiGen 同包附带 CLI,适合 shell 脚本和 CI 流水线:

```bash
export MEIGEN_API_TOKEN=meigen_sk_...
npx meigen gen --prompt "阳光厨房里的三花猫"
npx meigen gen -p "logo design" -m midjourney-v8.1 -r 1:1 --json
```

`--json` 输出机器可读、`--no-wait` 仅提交不轮询、`--reference <path|url>` 传参考图。完整参数 `npx meigen gen --help`。
