**MeiGen** 帮你在常用的 AI 工具中发现灵感，使用最新 AI 模型创建图片和视频。你可以安装 ChatGPT 插件、连接远程 MCP，或使用开源本地服务。

## ChatGPT

1. 打开 [ChatGPT 官方商店中的 MeiGen](https://chatgpt.com/plugins/plugin_asdk_app_6ab66d24f56481919361b6c33f7c1928)，选择 **Install**。
2. 登录 MeiGen 账号并完成连接，无需 API Key 或 Node.js。
3. 在对话中选择或提及 **MeiGen**，让它搜索灵感，或创建图片和视频。

试试：*“用 MeiGen 搜索极简产品摄影灵感，展示参考图片和对应的提示词。”*

搜索不消耗生成积分。生成使用 MeiGen 账号的充值积分，不使用每日免费积分；生成前确认模型、图片数量和总价。

ChatGPT 插件和远程 OAuth 连接使用 MeiGen Cloud。本地 npm 保留已有 MeiGen API Key 集成兼容，以及明确选用的外部供应商 BYOK；3.0.0 已移除 ComfyUI 与内置离线提示词库，详见[迁移说明](/zh/mcp/comfyui)。

## 作为上层工作流的工具

保留上层脚本、提示词、模型／供应商、数量和已批准预算，创意助手可选。使用持久化 UUID `requestId`、`wait: false`、结构化结果及 `check_generation` 提交首帧／视频并恢复，无需逐步重复审批。有限并发调度、预览和下载由上层负责。详见[完整工作流合同与示例](/zh/mcp/composable-workflows)。

## 什么是 MCP？

Model Context Protocol (MCP) 是一个开放标准，允许 AI 助手使用外部工具。当你将 MeiGen 安装为 MCP 服务器后，你的 AI 助手就能通过自然语言生成图片和视频、对 MeiGen 社区提示词画廊做语义搜索、增强提示词。通用远程 MCP 和本地 npm 支持匿名搜索公开灵感；官方 ChatGPT 插件的搜索需要账号授权。提示词增强属于本地工具。3.0.0 的灵感搜索仅访问在线画廊，不再提供离线回退；在线服务不可用会返回错误。

## 五项专用图片工作流

用自然语言要求抠图、商品详情图、营销海报、换背景或图片增强。Agent 应先读取 `list_skills`，准备真实材料，调用对应工具，再用 `check_skill` 查询结果；UUID 由 Agent 自行生成。已经指定的数量和质量就是你的指令，仅未定范围或 Upscale 警告需要进一步决定。

| 工作流 | 必需材料 | 可选材料 | 输出 |
| --- | --- | --- | --- |
| 透明抠图 | 一张原图 | 无 | 一张透明 PNG |
| 商品详情图 | 一张商品图及已选择的模块/数量 | 商品名、核实的卖点、Logo、模特图、两张额外角度图 | 1–6 张付费图 |
| 营销海报 | 品牌、活动或主题 | 文案、Logo、三张商品图、风格参考图 | 一张付费海报 |
| AI 换背景 | 一张商品图 | 模式；自定义模式必须提供背景描述 | 一张付费图 |
| 图片增强 | 一张原始静态 JPEG/PNG/WebP | 清晰或创意模式 | 一张付费增强图 |

Skills 只用购买积分，不提供免费次数或每日积分。BYOK 不提供这些工作流。详见[完整 Skills API 与素材指南](/zh/api-reference/skills/overview)。

海报的画面文案放在 `content`，设计要求放在 `extraNotes` 或 `customStyle`。`autoCopy: false` 忠实使用原文，选定语言仍可要求翻译。参见[海报字段用途与完整 MCP 调用示例](/zh/api-reference/skills/marketing-poster#mcp-调用示例)。

## 选择连接

ChatGPT 用户使用[官方插件](#chatgpt)。其他新用户通过[远程 OAuth](/zh/mcp/remote)连接 `https://www.meigen.ai/api/mcp`，在客户端登录 MeiGen 并授权；无需创建 API Key 或安装 Node.js。不支持 OAuth 时请使用兼容客户端。

[本地 npm](/zh/mcp/setup)保留既有 API Key 的生成、公开搜索和 Skills 兼容，以及 BYOK、本地文件处理、提示词增强和本地偏好。它没有 OAuth 登录，也不提供私人资料库。API Key 不是新用户的另一种认证选项。Claude／OpenClaw 插件附带的旧版 stdio 连接与创意指引独立更新，切换连接时避免重复工具。

3.0.0 本地普通生图仍支持 MeiGen（已有旧 Key）和 OpenAI 兼容供应商；优先级为 MeiGen → OpenAI 兼容。ComfyUI 不再支持，五项 Skills 与视频仍由 MeiGen 云端提供。模型与价格以 `list_models`、`list_skills` 为准。

## 工具

以下 **14 个共享工具**构成公共集合。本地 npm 3.0.0 有 16 个工具，包含两个本地辅助工具。通用远程 MCP 有 19 个，包含下方五个私人资料库工具。当前已发布的 ChatGPT 官方插件有 14 个工具；升级为 19 个工具、每批六条搜索结果的版本仍待商店审核。后端或 npm 发布不代表 ChatGPT 新功能已可用。

| 工具 | 用途 | MeiGen 账号授权 |
| --- | --- | --- |
| `generate_image` | 通用图片生成，本地可使用已配置的后端 | MeiGen Cloud 需要 |
| `generate_video` | MeiGen Cloud 视频生成 | 是 |
| `check_generation` | 按 generationId 或 requestId 查询／恢复 | 按请求 ID 查询需要授权所属账号 |
| `list_models` | 当前模型与能力 | 否 |
| `search_gallery` | 搜索公开提示词和图片预览，各连接的每批上限见下表 | 通用 MCP／本地可选；官方 ChatGPT 插件必须授权 |
| `get_inspiration` | 读取公开画廊条目 | 否 |
| `list_skills` | 五项工作流、材料、实时价格和输入参数 | 否 |
| `upload_skill_image` | 准备真实图片 URL 或附件字节 | 是 |
| `remove_background` | 一张透明抠图 | 是 |
| `generate_product_detail_images` | 1–6 张付费商品模块图 | 是 |
| `generate_marketing_poster` | 一张营销海报 | 是 |
| `generate_ai_background` | 一张纯白、智能或自定义背景图 | 是 |
| `upscale_image` | 增强一张原始静态图片 | 是 |
| `check_skill` | 私有 Skill 回执、模块状态和恢复 | 是，所属账号；旧版本地调用须使用原 Key |

本地另有 `enhance_prompt` 和 `manage_preferences`，均不需要 MeiGen 账号。3.0.0 不再提供 `comfyui_workflow` 或离线提示词回退。

| 公开画廊搜索 | 每批默认／最多条数 | 账号访问 |
| --- | --- | --- |
| 通用远程 MCP | 3／3 | 可选 OAuth；匿名搜索按 IP 限流 |
| 本地 npm 3.0.0 | 3／3 | 匿名，或兼容已有旧版 Key |
| 官方 ChatGPT 插件 | 已发布版本：3／3；待商店审核的更新：6／6 | 必须 OAuth 授权搜索权限（`meigen:search`） |

授权搜索使用账号[每日搜索额度](/zh/features/gallery#搜索)，不消耗生成积分。开始一次搜索计入额度，后续翻页不重复计数。通用远程 MCP 与本地 3.0.0 支持分页；ChatGPT 官方插件的换批卡片属于待商店审核的更新。查看同方向下一批时，保留返回的查询词和快照 ID，将 `nextOffset` 传为 `offset`；`hasMore=false` 时停止。换方向则开始新查询。生成请求恢复仍保留原 ID，不能因超时重新创建付费任务。

## 通过远程 OAuth 访问私人资料库

通用远程 MCP 提供 `search_favorites`、`list_boards`、`search_history`、`get_library_item` 和 `save_favorite`。通过 OAuth 连接，并在请求时分别同意资料库读取／写入权限；已有连接不会自动获得新权限。本地 npm 和 API Key 不支持这些工具。ChatGPT 官方插件新增这些工具的版本仍待商店审核。

列表只返回最多 500 个 Unicode 码点的 prompt 摘要。选定作品后用 `get_library_item` 分页读取用户提示词，默认 8000、最多 16000 码点；不返回内部 Skill 提示词。收藏须用户明确要求或事先允许，重复保存不会取消收藏或覆盖备注，只能存入自己的私密画板。收藏是偏好参考，不能代替用户当前要求。


<Note>
  视频能力因模型而异 — 画质档位、可选时长与分辨率、音频、参考视频续写，以及是否必须提供首帧图。部分模型仅支持图生视频。当前清单用 `list_models` 查，或见[模型对比](/zh/features/models)。

  Seedance 2.5 的模型 ID 是 `seedance-2-5`，支持 4–30 秒、480p/720p/1080p 输出和参考视频续写，没有 `tier` 参数。

  `generate_video` 必须显式指定 `model`——平台没有默认模型。参考素材都是数组：`referenceVideos`（mp4 / mov）和 `referenceAudios`（wav / mp3，单条 ≤15MB）。**本地 npm 服务器支持直接传本地文件路径**并自动上传；远程服务器只接受已经指向 `images.meigen.ai` 的地址 —— 此前生成结果的 `videoUrl`，或通过 [`POST /api/upload/reference-video`](/zh/api-reference/endpoint/generate#上传参考视频与音频) 上传的文件。任意公网 URL 会在扣点前被拒。单数形式 `referenceVideo` 仍作为只含一项的别名受理；`referenceVideoDuration` 是已弃用且会被校验的兼容提示，不会决定计费时长 —— 请省略它，服务端会逐条探测。

  各模型上限从 `list_models` 读取（`capabilities.video.referenceVideo` 与 `capabilities.video.referenceAudio`）：Seedance 2.5 最多 10 条视频和 10 条音频，每类单条 2–30 秒、合计 30 秒；Seedance 2.0 各最多 3 条，单条 2–15 秒、合计 15 秒。**Seedance 2.0 不能只靠音频生成** —— 它的参考音频必须搭配至少 1 张参考图或 1 条参考视频；Seedance 2.5 则允许纯音频请求。

  计费按参考视频时长的**总和** + 你的输出时长，且不低于最低计费秒数。参考音频免费：不计入这个总和，只带音频、不带参考视频的请求按该模型的直接生成价计费。
</Note>

### GPT Image 2.5

先调用 `list_models` 确认可用性。**本地 npm 3.0.0 支持** `model: "gpt-image-2.5"` 或别名 `modelId`、`quality`（`low`、`medium`、`high`、`xhigh`、`max`），以及 `modelVariant: "sunburst"`（默认）或 `"flare"`。同时传入 `model` 和 `modelId` 时两者必须相同。[远程 MCP 服务](/zh/mcp/remote)与 [REST API](/zh/api-reference/endpoint/generate) 使用 `modelId` 搭配 `modelVariant`。GPT Image 2 作为独立模型保留原有价格。
