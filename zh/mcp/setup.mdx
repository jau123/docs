## 新连接：使用账号登录

ChatGPT 用户[从官方商店安装 MeiGen](/zh/mcp/overview#chatgpt)并登录。其他用户在支持 OAuth 的 MCP 客户端中添加 Streamable HTTP 地址 `https://www.meigen.ai/api/mcp`，选择**连接／认证**，登录 MeiGen 并授权；无需 API Key 或 Node.js。Claude、Codex、Cursor 等客户端步骤见[远程接入](/zh/mcp/remote)。

客户端不支持 OAuth 时，请使用兼容客户端或 ChatGPT 官方插件。API Key 仅保留已有旧版集成的兼容，不作为新用户的另一种认证方式。不要在聊天发送凭据。

收藏、画板、历史记录、提示词详情和保存可通过通用远程 MCP 的 OAuth 连接使用，本地 npm 和 API Key 均不可访问。ChatGPT 官方商店的新增工具仍待审核；安装当前已发布插件不会启用这些功能。

## 复制给助手连接

```text
通过远程 OAuth 连接 https://www.meigen.ai/api/mcp。
保留其他服务并复用已有 MeiGen 条目。从固定 API Key 切换时移除 Authorization
请求头，让我在客户端完成登录。不要创建新 Key，也不要在聊天索要凭据。
仅在需要时保留已有旧版集成或 BYOK，不添加重复的 MeiGen 工具。
重连后调用 list_skills 并报告实际结果；不要为验证而上传、生成或消耗积分。
说明尚未验证的步骤。
```

## 已有本地集成与 BYOK

下列配置仅用于维护现有 stdio／API Key 集成或明确选用的 OpenAI 兼容供应商。本地 npm 没有 OAuth 登录，也不提供私人资料库工具；它可处理宿主可读取的本地文件、保存普通生成结果、增强提示词并记录本机偏好。

<Note>
  npm **3.0.0 是当前主版本**。升级前阅读 [3.0 迁移说明](/zh/mcp/comfyui)：ComfyUI 与内置提示词库已移除，在线搜索没有离线回退。下方示例均明确固定此版本。
</Note>

本地建议 Node.js 22+。仅将现有 Key 私密保留为 `MEIGEN_API_TOKEN`，不要为这些示例创建新的 MeiGen Key。下方片段只展示相关字段，不要用它们整体替换已有条目或配置文件。

```json
{
  "mcpServers": {
    "meigen": {
      "command": "npx",
      "args": ["-y", "meigen@3.0.0"]
    }
  }
}
```

已有凭据通过 MCP 进程环境或客户端私密设置传入，不写入共享 JSON。`~/.config/meigen/config.json` 中的现有私密配置仍兼容；配置变化后需重启／重连。

### 已有编辑器连接

已有 Cursor、VS Code、Windsurf、Roo 或 Claude 连接，请手动编辑原 MeiGen 条目。只将 `args` 中的包参数改为 `meigen@3.0.0`，保留启动命令、其他参数、`env`、环境变量转发、超时、宿主专属设置及所有其他 MCP 条目。已有私密凭据保持原样。

不要对已有配置运行已发布 2.0.2 的初始化命令：它可能直接替换 MeiGen 条目，无法保留原设置。启动命令使用不熟悉的包装脚本，或找不到明确的 MeiGen 包参数时，保持配置不变，先核实宿主的配置方式。保留明确的固定版本，不使用无版本包名或 `@latest`，避免将来意外升级主版本。新连接使用[远程 OAuth](/zh/mcp/remote)。

### 已有 Codex stdio 配置

新用户使用[远程 OAuth](/zh/mcp/remote)；已有本地集成可保留以下条目，不同时添加重复远程连接：

```toml
[mcp_servers.meigen]
command = "npx"
args = ["-y", "meigen@3.0.0"]
env_vars = ["MEIGEN_API_TOKEN"]
startup_timeout_sec = 90
tool_timeout_sec = 240
```

宿主需要继承已有环境变量，项目 `.env.local` 不会自动加载。没有变量时，匿名公开查询可省略 `env_vars`。较长视频任务可能需要更多时间；中断时按原 generationId 或已保存的 requestId 恢复，不另建付费任务。

### 已有 Claude／OpenClaw 插件

Claude marketplace 与 OpenClaw bundle 可能附带本地 stdio 连接，其版本和指引文件独立于 npm 更新。切换 OAuth 时检查已安装连接，仅保留一套有效 MeiGen 服务。独立 ClawHub Skill 只提供指引，不代表 MCP 已连接；分发方式见[源码仓指南](https://github.com/jau123/MeiGen-AI-Design-MCP#quick-start)。

### Hermes Agent (NousResearch)

新建 MeiGen 连接应使用[远程 OAuth](/zh/mcp/remote)。维护已有本地 Hermes 集成、并需要等待长视频任务时，将以下超时设置合并到 `~/.hermes/config.yaml` 的原条目，保留已有的私密环境变量配置：

```yaml
mcp_servers:
  meigen:
    command: "npx"
    args: ["-y", "meigen@3.0.0"]
    timeout: 2700
    connect_timeout: 120
```

`timeout: 2700` 允许单次工具调用等待最多 45 分钟；`connect_timeout: 120` 为首次 npm 下载预留时间。这是长时间等待的建议配置，不是生成时限或完成保证。配置字段见 [Hermes 官方 MCP 文档](https://hermes-agent.nousresearch.com/docs/reference/mcp-config-reference/)。

宿主超时不会取消已受理任务或触发退款。组合工作流优先使用 `wait: false`、持久化 UUID `requestId` 和 `download: false`，用原 generationId 或 requestId 调用 `check_generation` 恢复；需要重交时仍保留原 ID 和精确参数。详见[工作流恢复](/zh/mcp/composable-workflows)。

### 旧版 CLI

已有 CLI 集成可继续私密使用原 `MEIGEN_API_TOKEN`：

```bash
npx -y meigen@3.0.0 gen --prompt "柔和窗光下的陶瓷咖啡杯"
npx -y meigen@3.0.0 gen -p "产品主图" --ref ~/Desktop/bottle.jpg
npx -y meigen@3.0.0 gen --help
```

生成示例属于付费动作，不能用来测试连接。`--json` 返回结构化结果；`--no-wait` 仅提交、不轮询。保留返回的任务 ID 和精确输入以便恢复。

### OpenAI 兼容普通生图

明确选用 BYOK 时，在私密本地设置中保留 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`，使用供应商实际支持的模型及计费。BYOK 不提供 MeiGen 视频、五项专用 Skills 或私人资料库。3.0.0 本地供应商优先级为 MeiGen（已有旧 Key）→ OpenAI 兼容；已移除的 ComfyUI provider 会被拒绝，不会自动转成付费供应商。

## 输出目录

普通本地生成和 CLI 可保存结果；专用 Skills 返回 URL／资源，需要时显式下载。

| 类型 | 默认目录 | 覆盖变量 | Linux 回退 |
| --- | --- | --- | --- |
| 图片 | `~/Pictures/meigen/` | `MEIGEN_OUTPUT_DIR` | `XDG_PICTURES_DIR` |
| 视频 | `~/Movies/meigen/` | `MEIGEN_VIDEO_OUTPUT_DIR` | `XDG_VIDEOS_DIR` |

## 验证与恢复

连接后询问“列出 MeiGen 的 Skills 和当前价格”，确认 `list_skills` 实际调用成功。此公开查询不证明账号授权或付费余额有效，不要为了测试连接生成图片。

未授权时通过 OAuth 重连；仅已有旧版集成可私密检查原 Key。余额不足时使用所连接账号的[个人主页充值](https://www.meigen.ai/profile)，生成消耗购买积分，不使用每日免费积分。价格以 `list_models`／`list_skills` 为准。

普通任务中断时用 `check_generation`；Skill 用 `check_skill` 与原回执、精确输入恢复。上传错误、缩小尺寸确认、价格变化及退款遵循实际返回动作。详见[工作流合同](/zh/mcp/composable-workflows)和 [Skills 指南](/zh/api-reference/skills/overview)。
